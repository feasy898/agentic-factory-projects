## 1. 全角→半角（`to_halfwidth`，normalize.py:22-24, 42-44）

- 基准字符集 **0xFF01–0xFF5E ↔ 0x21–0x7E**（全角 ASCII 可打印区 94 字：０-９、Ａ-Ｚ、ａ-ｚ
  与常见全角符号），外加全角空格 **0x3000 → 半角空格**；
- `str.translate` 一次映射，1:1 长度不变——识别层影子扫描依赖此性质（span 与原文严格对齐，
  见 recognizers-rule spec §3）。

## 2. 数字串类公共归一（`normalize_digits`，normalize.py:27-36, 47-49）

适用类别 `ID_CARD / PHONE_MOBILE / PHONE_LANDLINE / BANK_CARD / USCC`
（normalize.py:27-33 `_DIGIT_TYPES`）：

1. 全角→半角；
2. 删除全部内部分隔符字符集：**半角+全角空格、`\t`、`\r`、`\n`、`-`、Unicode 连字符类
   （‐‑‒–—―）、全角减号 `－`、`.`、全角点 `．`、中文间隔点 `·`**（normalize.py:36
   `_SEPARATORS`，单字符串逐字面删除；**不含 `+`**——加号只在 PHONE_MOBILE 前缀剥离中处理）。

## 3. 逐类别归一化表（`normalize_value`，normalize.py:52-84）

| 类别 | 规则 | 例 → 期望 normalized | 冻结细节 |
|---|---|---|---|
| `PHONE_MOBILE` | 公共归一后去 **+86/86 前缀**：先剥单个前导 `+`（若有）得 body；仅当 `len(body)==13` 且 `body` 以 `86` 开头且第 3 位为 `1`、第 4 位 ∈ 3-9 才视为前缀，返回 `body[2:]`；**否则原样返回 digits（含可能残留的前导 `+`）** | `＋86 138 0013 8000` → `13800138000`；`138 0013 8000` → `13800138000`；`138．0013．8000` → `13800138000`；`+13800138000`（+开头但非 86 前缀）→ `+13800138000`（`+` 保留） | normalize.py:63-70；识别端 span 回扩覆盖 `+`（recognizers/rule/detect.py:417-419） |
| `ID_CARD` | 公共归一后**末位 x→X**（仅末位；`endswith(("x","X"))` → `[:-1]+"X"`） | `110105 19491231 002x` → `11010519491231002X`；全角 `Ｘ` 尾经半角化同判 | normalize.py:71-73 |
| `PLATE` | 公共归一后**大写**（间隔点 `·` 已被公共归一删除；中文省份字符不受大写影响） | `琼A·12345` → `琼A12345`；`琼a-12345` → `琼A12345`；`琼Ａ１２３４５` → `琼A12345` | normalize.py:74-75 |
| `DATE_BIRTH` | 半角化+去首尾空白后匹配 `(\d{4})[年./-](\d{1,2})[月./-](\d{1,2})日?` **fullmatch** → `YYYY-MM-DD`（月/日补零，`int` 去前导零）；无法解析**原样返回（半角化后）**。字符类是「年、`.`、`/`、`-`」四选一（`-` 在字符类尾部按字面量），**顿号 `、` 不是候选分隔符**；**fullmatch 只验形状、不做月/日值域校验**——`1990年13月40日` → `1990-13-40`、`1990/2/30` → `1990-02-30` 照常补零输出（2026-09-30 二轮裁定钉死：normalize.py:78-80 无 1–12/1–31 范围检查，实测取值如左；二轮重生成件一致） | `1990年3月7日` → `1990-03-07`；`1990/3/7` → `1990-03-07`；`1990.03.07` → `1990-03-07`；`１９９０年０３月０７日` → `1990-03-07`；`1990年3月`（缺日）→ `１９９０年３月` 的半角化原样 | normalize.py:38-39, 76-81 `_DATE_PARTS_RE` fullmatch |
| 其余数字串类（`PHONE_LANDLINE / BANK_CARD / USCC`） | 公共归一 | `6222 0210 0111 6295 763` → `6222021001116295763` | normalize.py:82-83 |
| `EMAIL / IP / SECRET_KEY` 及词面类 | 仅全角→半角 + 首尾去空白（原样语义，保守安全；**大小写不归一**——`Ｕｓｅｒ＠…` → `User@…` 保留原大小写） | `Ｕｓｅｒ＠ChengMai.gov.cn` → `User@ChengMai.gov.cn` | normalize.py:84 |
