# 注入检测模式词表（recognizers/semantic，T4.2 第一档）。本文件是运营可改的权威副本；
# 文件缺失/为空时回退 recognizers/semantic/patterns.py 内置默认（两者内容保持一致）。
# 行格式：<class>|<regex>（# 注释）。class ∈ STRONG / EXFIL / WEAK：
#   STRONG  强特征：指令覆盖/角色接管/提示词窃取/对用户隐匿——任意位置命中即判；
#   EXFIL   外发链：工具调用诱导 + 明确外发目的地——任意位置命中即判；
#   WEAK    弱特征：须位置启发佐证（正文深处/括注内/收束用语后/行首标记）才判。
# 反误拦护栏（代码内建，词表不写）：命中点前方 8 字符内出现
#   禁止/严禁/不得/切勿/请勿/不要/避免/防止/无需/无须/不可/不能/勿/别 → 该命中不计。
# 注意：本文件是公开仓库源码面——只写模式与类别，不写任何真实产品/模型/库名。
