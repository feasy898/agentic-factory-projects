## 1. 总体架构与数据流

```
                         ┌──────────────────────────────────────────────┐
   Kenney CC0 素材 ──►  assetkit（压图/转音频/精简字体/图集）                  │
   用户素材 / 截图   ──►  [路径B] director(VLM) ─► PlayableSpec 草稿 ─┐        │
                         [路径A] 人工/预制 golden spec ──────────────┤        │
                                                                    ▼        │
                                                       PlayableSpec JSON     │
                                                    (schema v1 校验，M1)     │
                                                                    ▼        │
   模板×4 (Phaser, TS)  ◄── spec 驱动渲染 ──  orchestrator (Python CLI)          │
        │ engine-bridge (M2)：PF.open/静音策略/事件/渠道退出接口               │
        ▼                                                                     │
   packager (M4)：esbuild 打包 + channel-rules.json 配置驱动                    │
        ├── applovin/meta/unity → 单 HTML 全内联（base64）
        ├── google/mintegral → zip（mintegral 实测为 build.js + Template.html 结构）
        └── tiktok/pangle → zip（+ config.json + sdk js）
        ▼                                                                     │
   qacore (M8)：Playwright 无头质检（10 项检查，见 §7-M8）──► 质检报告 JSON+HTML │
        ▼                                                                     │
   产物 artifacts/<project>/<channel>/<locale>/  + 预览页 + 二维码 ◄── webui(10)┘
```

关键决策（三条主轴）：
1. **打包器双轨制**：D1 先用上游成熟 CLI 跑通 6 渠道出包（跑通开源组合）；自研配置驱动 packer 为主轨（esbuild + channel-rules.json，模块内可重生成），上游 CLI 留作交叉验证对照轨。这样既满足"先跑通开源件"，又满足法务"公开仓库无上游名"。
2. **运行时桥自研**：渠道运行时接口很小（就绪等待 / open / 静音 / 退出），自研 `engine-bridge`（TS，~300 行），不做对上游 SDK 的运行时硬依赖；上游 SDK 仅在 D1 spike 与对照轨使用。
3. **QC 是唯一裁判**：不信任任何打包器，产物过不过 qacore 说了算；渠道合规知识全部冻结在 `channel-rules.json`（我们自己的资产），规范变化只改配置。

## 4. PlayableSpec JSON Schema（v1.0.0，D2 冻结）

`packages\spec\playable-spec.schema.json`（JSON Schema draft 2020-12）。顶层：

```json
{
  "specVersion": "1.0.0",
  "meta":     { "projectId": "str(id)", "title": "str", "seed": "int" },
  "game": {
    "template": "match3 | merge | pullpin | sort",
    "params":  { "...": "模板子schema，见 §4.1" },
    "difficulty": { "targetLevel": "0-1 float" },
    "attract": { "nearWin": "bool", "failBait": "bool", "firstClickSucceed": "bool" },
    "durationBudgetSec": { "target": 20, "max": 30 }
  },
  "flow": {
    "tutorial": { "enabled": true, "gesture": "tap|drag", "maxSec": 3 },
    "endScreen": { "showScore": "bool", "ctaKey": "str(i18n键)", "landingUrl": "uri" }
  },
  "assets": {
    "background": "path", "sprites": { "key": "path", "...": "..." },
    "audio": { "tap": "path|null", "win": "path|null" },
    "fontSubset": "path(由assetkit生成)"
  },
  "i18n": {
    "defaultLocale": "en",
    "locales": ["en","ja","ko","pt-BR","de","ar"],
    "strings": { "<locale>": { "cta": "str", "tutorial": "str", "win": "str", "lose": "str", "score": "str" } },
    "rtl": ["ar"]
  },
  "channels": {
    "targets": ["applovin","unity","google","meta","tiktok","mintegral"],
    "orientation": "portrait|landscape|both",
    "overrides": { "<channel>": { "maxBytes": "int", "ctaStyle": "str" } }
  },
  "variants": [ { "id": "v1", "seed": 1, "palette": "A|B|C" } ],
  "qc": { "maxLoadSec": 2.0, "autoplayTimeoutSec": 45 }
}
```

### 4.1 模板子 schema（params，冻结）

| template | params（全部带默认值，LLM 只需填偏差项） |
|---|---|
| match3 | `cols`(6), `rows`(6), `moves`(15), `colors`(5), `goalType`("clear-jelly"|"score"), `goalCount`(30), `spriteKeys`(5个棋子键) |
| merge | `cols`(5), `rows`(5), `maxTier`(5), `spawnTierMax`(2), `goalTier`(4), `spriteKeys`(按 tier) |
| pullpin | `levels`(3), `pinsPerLevel`(3-5), `hazard`("lava"|"spike"), `rescuee`("character"), `orderSolution`(数组,由seed生成校验可解) |
| sort | `rods`(4), `layersPerRod`(4), `colors`(4), `screwMode`(bool: 拧螺丝变体), `moveLimit` |

不变式（validator 强制）：pullpin 必须可解（模拟验证）；sort 初始状态必须有解（栈可逆校验）；match3 初始盘面存在可行步；durationBudgetSec.max ≤ 30；i18n.locales 内每语言 strings 键全。

### 4.2 运行时契约（模板与桥之间，冻结）

- 全局对象 `window.PF`：`PF.open(url)`（按渠道路由退出接口）、`PF.isMuted()`、`PF.locale`
- 事件（DOM CustomEvent，冒泡到 document）：`pf:ready`、`pf:start`、`pf:first-interaction`、`pf:end {win}`、`pf:cta`
- QC 钩子 `window.__PF_QC__`：`hint(): {x,y,type}|null`（返回"当前最优下一步"的真实坐标，QC 用真实 pointer 事件点击）、`state(): string`（"loading|tutorial|playing|end"）
- 静音策略：所有音频经 PF 音频管理器创建；首个 `pf:first-interaction` 前强制 muted（HTMLAudio muted=true / AudioContext suspended）

## 6. 每模块 SPEC + EVAL（验收命令在本机可真实运行）

### M7 director（演示级）

- 通过线：≥3/5（演示级门槛，未达也不阻塞主路径）。

### M8 qacore（核心资产，自身有 eval）
- SPEC：对单个产物文件跑 10 项检查，输出 report.json + HTML，任何 FAIL → exit 1。
  - CHK01 大小：≤ channel-rules 上限（applovin 5MB 单HTML / meta 3MB（官方建议~2MB，内部从严）/ google zip 5MB / unity zip 5MB / tiktok 5MB / mintegral 5MB）
  - CHK02 文件数：google zip 条目 ≤512（内部目标 ≤200）
  - CHK03 零外网：Playwright route 拦截全部请求，除本机服务器外出现任何请求 → FAIL
