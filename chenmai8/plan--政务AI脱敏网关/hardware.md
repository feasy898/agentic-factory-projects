# Hardware —— 硬件需求说明

## 结论：无硬件采购需求。

## 说明

1. **开发与 MVP 构建全部在现有机 windev-01 上完成**（Windows Server 2022，16C125G 级、磁盘空闲 218G、无 GPU、无 Docker）：
   - 规则识别/脱敏/路由/审计/文件通道均为 CPU 轻载 Python；
   - OCR 走 RapidOCR + ONNX Runtime（纯 CPU）；
   - 语义层 Qwen3Guard-Gen-0.6B CPU 推理可跑（秒级，仅 prompt 侧采样），无 GPU 也可完成演示；
   - NER 训练延后，不需要现在准备任何硬件（见 training-plan.md）。
2. **训练期（10/8 之后）**：使用已有的 anolis-gpu-01（[内网地址已脱敏]，2×V100S-32GB，已在用），预计单卡 1.5–2.5 天卡时，无租赁预算需求；万一该机不可用，备选为按小时云 GPU ≤8 卡时（见 training-plan 风险 4），属或有小额支出，非采购。
3. **演示需要**（非采购、仅环境注记）：
   - 路演"双屏对比"用两台显示器或一台投影分屏即可；无条件时用浏览器双窗口并排 + 录屏软件（OBS 免费版）同样成立；
   - 演示视频录制：本机已有屏幕录制能力（OBS 或 Win+G），无需采集卡；
   - 上游 LLM：使用主会话提供的 OpenAI 兼容 API key（按量计费，预算极小：全量评测+质量评测估 < 50 万 token 量级），非硬件项。
4. 赛后迭代（浏览器插件、Transformers.js 本地推理）：目标形态即"无 GPU 的普通办公机可跑"，本机即可验证。
