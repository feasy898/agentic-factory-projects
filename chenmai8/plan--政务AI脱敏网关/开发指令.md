## 1. MVP 范围（10 天内）

### P0（必须有，缺一则 MVP 不成立）
- 网关：OpenAI 兼容 `/v1/chat/completions`（流式+非流式）、多上游适配（OpenAI 兼容协议，可切 bigmodel/DeepSeek/本地 mock）、部门 Key。
- 识别·规则层：身份证/统一社会信用代码/银行卡(Luhn)/手机/座机/车牌/邮箱/IP/密钥/出生日期 + 密级标识与"内部资料"字样；白名单（12345、单位座机、公开文号）。
- 可逆脱敏：会话稳定占位符（密钥哈希）、号码归一化（全角/空格/分隔符）、流式缓冲还原、工具调用参数还原。
- 敏感度路由：普通→互联网 / 敏感个人信息·工作秘密切政务云（演示用第二 mock 或本地 upstream）/ 密级→拦截。
- 输出侧：AI 生成标识（文本尾注 + 响应元数据字段）、拦截时的代答/拒答。
- 文件通道·文本层：docx/xlsx/pdf 文本解析 + 公开前体检报告 + 彻底删除式导出（PDF 重写内容流、Excel 删列而非隐藏）。

- 测评：合成测评集生成器（seed 固定、可复现）+ 指标计算（结构化号码召回、F1、延迟）+ e2e 泄漏检测。

### P1（时间允许必做，演示加分）

## 3. 总体架构与数据流

```
                 ┌────────────────────────────────────────────────────┐
 干部/WebUI/Dify │                gateway (FastAPI :9000)              │
 Open WebUI ────►│  /v1/chat/completions                               │
                 │   1 auth(dept key) → 2 detect(recognizers)          │
                 │   3 mask(masking) → 4 route(routing)                │
                 │      ├─ BLOCK ──────────► outguard 拒答/代答 ──┐     │
                 │      ├─ GOVCLOUD ─► upstream B(政务云/本地)    │     │
                 │      └─ INTERNET ─► upstream A(互联网模型)     │     │
                 │   5 流式还原(masking.remap) → 6 outguard 标识  │     │
                 │   7 audit 写库(只存脱敏) ◄─────────────────────┘     │
                 │  /v1/files/*  → filechannel (parse→detect→export)   │
                 │  /admin/*     → audit 查询/统计/导出 + webui 页面    │
                 └────────────────────────────────────────────────────┘
```

关键点：
- 上游全部是 OpenAI 兼容协议（httpx AsyncClient 直连）。**LiteLLM 不在 MVP 主链路**（理由见 §11 风险 1），作为可选集成与文档演示（"改 baseURL 即接入"）。

## 5. 冻结契约（D1 评审后不改；字段只增不改名不删）

### 5.1 Finding（识别结果，recognizers → 一切下游）

```json
{
  "fid": "f_0001",                // 请求内自增
  "type": "ID_CARD",              // EntityClass，见 5.1.1
  "layer": "rule",                // rule | ner | semantic
  "start": 12, "end": 26,         // 原文 char span（Python 切片语义）
  "raw": "460022199003071234",    // 原文（仅内存/调试，禁止入审计）
  "normalized": "460022199003071234",  // 归一化值（见 5.3.2）
  "confidence": 1.0,              // 规则命中校验位=1.0；NER=模型分
  "whitelisted": false,           // 命中白名单则 true，且不参与脱敏
  "action_hint": "MASK"           // MASK | ROUTE_FLAG | BLOCK_FLAG
}
```

5.1.1 EntityClass 枚举（值即代码常量，中文标签用于占位符）：
`PERSON(人名) ADDRESS(住址) ID_CARD(身份证) PHONE_MOBILE(手机号) PHONE_LANDLINE(座机) BANK_CARD(银行卡) USCC(信用代码) PLATE(车牌) EMAIL(邮箱) IP(地址) SECRET_KEY(密钥) DATE_BIRTH(出生日期) SENSITIVE_ATTR(敏感属性) WORK_SECRET(工作秘密) CLASSIFICATION_MARK(密级标识) INJECTION(注入指令) ORG_INTERNAL(内部机构/项目) DOC_NUMBER(文号,白名单候选) OTHER(其他)`
敏感属性细分（SENSITIVE_ATTR 子类型，写 subtype 字段）：病症/残障/低保特困/社区矫正/信访人/金融账户/行踪轨迹/犯罪记录/特定身份。对齐 GB/T 45574-2025 敏感个人信息类别（标准全文未逐字核实，D1 由文档任务比对公开摘要确认，见 §12）。

### 5.2 RouteDecision（routing → gateway）

```json
{
  "route": "INTERNET",            // INTERNET | GOVCLOUD | BLOCK
  "reasons": [                    // 有序，第一条为决定性理由
    {"code": "CLASSIFICATION_MARK", "fid": "f_0007", "detail": "命中 机密★"}
  ],
  "upstream": "govcloud_local",   // config/app.yaml 上游名；BLOCK 时为 null
  "mask_required": true,
  "labels": {"ai_generated": true}
}
```

决策矩阵（优先级 BLOCK > GOVCLOUD > INTERNET，D2 冻结）：

| 命中 | 路由 | 备注 |
|---|---|---|
| CLASSIFICATION_MARK（机密★/秘密★/内部资料 注意保密 等） | BLOCK | 返回保密提示，403 语义 |
| INJECTION（语义层/规则） | BLOCK（P0） | 记录 flag=injection |
| WORK_SECRET 或 SENSITIVE_ATTR | GOVCLOUD | 即便已脱敏也切政务云 |
| ID_CARD/BANK_CARD 同请求 ≥3 个（名单场景） | GOVCLOUD | 批量名单 |
| 单个结构化 PII（ID_CARD/PHONE/BANK/USCC/PLATE/EMAIL/IP/SECRET_KEY/DATE_BIRTH/PERSON/ADDRESS） | INTERNET（脱敏后） | mask_required=true |
| 仅白名单命中/无命中 | INTERNET | mask_required 按实际 findings |

### 5.3 MaskingMapping（masking 内部 + /internal/anonymize 输出）

5.3.1 占位符算法（冻结）：
```
digest = HMAC-SHA256(key=MASK_KEY, msg=f"{session_id}\x1f{type}\x1f{normalized}").hexdigest()
digest8 = digest[:8]；同 session+type 内碰撞则升 10 位（插入时检测）
placeholder = "〔" + 中文标签 + "·" + digest8 + "〕"    // 例：〔人名·7f3a2b1c〕
```
- 会话稳定：同 session 同值 → 恒同占位符；跨 session 因 session_id 参与 → 不同（设计如此，演示时说明）。
- 归一化等价：同一号码的不同写法 → 同 normalized → 同占位符。

5.3.2 归一化规则（masking/normalize.py，冻结）：
- 数字串：全角→半角、删除内部空格/连字符/点号/全角空格；
- PHONE_MOBILE：去 +86/86 前缀；ID_CARD：末位 x→X；PLATE：去间隔点+大写；EMAIL：原样（大小写不敏感）；IP：原样；SECRET_KEY：去引号空白；
- DATE_BIRTH：中文/ISO 等写法 → YYYY-MM-DD；
- PERSON/ADDRESS：不做串级归一化（原样），仅精确匹配去重。

5.3.3 MappingEntry：
```json
{"placeholder": "〔手机号·9a1b2c3d〕", "type": "PHONE_MOBILE",
 "normalized": "13800138000", "first_seen": "2026-09-28T03:00:00Z",
 "session_id": "sess_...", "preserve_semantic": false}
```
会话存储：内存 LRU + SQLite 落盘（表 masking_map），TTL 默认 24h 可配。

### 5.4 AuditEvent（audit 存储/查询，冻结；禁止出现 raw）

```json
{
  "ts": "2026-09-28T03:00:00Z", "request_id": "req_...", "session_id": "sess_...",
  "dept": "民政局",                       // 由 dept key 反查
  "route": "GOVCLOUD", "blocked": false,
  "reasons": ["SENSITIVE_ATTR"],
  "class_counts": {"ID_CARD": 2, "PHONE_MOBILE": 3},
  "prompt_preview": "〔人名·7f3a2b1c〕提交的〔身份证·…〕…",   // ≤500字符，已脱敏
  "response_preview": "…",                                     // ≤500字符，已还原后仅含占位符版本
  "upstream": "govcloud_local", "latency_ms": 812, "flags": []
}
```
库表：audit_events（上述字段+id 自增）；masking_map 单独表。入库前跑 `assert_no_raw_pii()`（用本次请求的 normalized 值列表做断言，失败即 500 且不落库）。

### 5.5 FileReport / 导出结果（filechannel）

```json
{
  "file_id": "file_...", "filename": "低保公示.pdf", "sha256": "...",
  "kind": "pdf|docx|xlsx|scan_pdf", "pages": 3,
  "findings": [ {"page": 1, "bbox": [x0,y0,x1,y1], "finding": {Finding}} ],
  "risk_level": "HIGH",                  // HIGH: 含SENSITIVE_ATTR/批量ID; MID: 结构化PII; LOW/none
  "summary": {"ID_CARD": 12, "PERSON": 30}
}
```
导出端点返回二进制 + `X-Report-Id`。验收口径（铁律）：**对导出物重新走"解析+检测"，seeded PII 命中数必须为 0**（PDF 文本层重抽取、xlsx 重开读值、docx 重抽取）。

### 5.6 HTTP API（OpenAI 之外均为内部/管理面）

| 方法 路径 | 说明 |
|---|---|
| POST `/v1/chat/completions` | OpenAI 兼容，body 同 OpenAI（stream 支持）；鉴权 `Authorization: Bearer <dept_key>`；响应附 `x-anongw-route`、`x-anongw-request-id` 头；AI 标识：非流式在 `choices[0].message.content` 尾部加标识行 + `annotations` 字段；流式在最后一个 delta 尾部加标识行 |

| GET `/admin/api/audit` | 分页查询（dept/from/to/route/blocked） |
| GET `/admin/api/metrics` | 按部门/路由/拦截类别聚合 |
| GET `/admin/api/report.csv` | 保密自查报告导出 |
| POST `/internal/detect` | `{text}` → findings+归一化（调试） |

| GET `/healthz` | 存活 |

### M2 recognizers（三层识别；MVP=规则层）
- spec（规则层）：
  - 正则 + 校验位：ID_CARD（GB11643 校验位）、USCC（GB32174 校验位）、BANK_CARD（Luhn）、PHONE_MOBILE（1[3-9]\d{9}，容许分隔）、PHONE_LANDLINE（区号-号码，白名单可豁免）、PLATE（含新能源）、EMAIL、IPv4、SECRET_KEY（sk-/AKIA/-----BEGIN/private_key 长熵串）、DATE_BIRTH（配合上下文"出生/生于"）；

- eval：`python -m evals.m2_recognizers` —— 用 `data/cases/rule_cases.jsonl`（D1 由 M8 生成器产出 ≥300 例：每类别 ≥20 正例含扰动变体 + 白名单负例 ≥40 + 密级样例 ≥20）：

### M3 masking（可逆脱敏，本项目的原创核心）
- spec：
  - §5.3 全部算法；会话存储（内存+SQLite，TTL）；
  - 非流式还原：正则替换占位符→原值；
  - **流式还原（masking/remap.py）**：状态机扫描 SSE 增量流；一旦出现 `〔` 即开始缓冲，直到完整匹配 `〔<标签>·<hex8-10>〕`（≤32 字符）则查映射表替换为原值后发出；缓冲超 32 字符仍无 `〕` 判定为普通文本放行；占位符被上游切进两个 SSE chunk 时必须正确还原（ fuzz：对同一回答按 1–7 字节随机切块，还原结果必须与整段还原一致）；
  - 工具调用：流式下 tool_call.arguments 增量累积，finish 前不发（spec 明示此行为变化），finish 时整体还原后作为单个 delta 发出；非流式直接整体还原；
  - 语义保留替换（P1）：ID_CARD 保留前 6 位地区码+出生 YYYY，其余位随机但过校验位；DATE 整体平移 ±N 天（N 按会话固定）。
- eval：`python -m evals.m3_masking` ——
  - 稳定性：1000 值 × 同 session 重复请求占位符全等；跨 session 不同；
  - 归一化等价：全角/空格/分隔符变体 → 同占位符；
  - 流式 fuzz：500 条随机切块用例还原全等；
  - 工具调用还原：含中文参数 JSON 的 delta 序列还原正确；
  - 碰撞：10 万值插入零碰撞（8 位 hex 空间抽样验证 + 插入期检测逻辑单测）；
  - 性能：含 50 个占位符的 2000 字还原 < 20ms。
- 通过线：全过。
