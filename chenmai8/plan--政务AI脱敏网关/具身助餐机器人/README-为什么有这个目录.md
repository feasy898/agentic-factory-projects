# 为什么这里有这个目录？（2026-09-28 修复工留）

本目录下的 `repo` 是一个 **Windows 目录联接（junction）**，指向真实仓库：

```
政务AI脱敏网关\plan\具身助餐机器人\repo  ──junction──▶  具身助餐机器人\repo
```

原因：「助餐机器人G0-G1构建工作流」被保存在 `政务AI脱敏网关\plan\.zcode` 项目键下，
其脚本用相对路径 `具身助餐机器人/repo/scripts/gate_g1.py` 调 G1 验收门，
相对 cwd（= 本 plan 目录）解析后指向不存在的路径，导致第 1 轮验收门
`[Errno 2] No such file or directory`。建此联接使命令解析到真实仓库；
门脚本内部 `Path(__file__).resolve()` 会穿透明联接，实际运行的仍是真实仓库的门禁。

处置建议：
- 若工作流已改用绝对路径（草稿 2026-09-28 已改为 `REPO + "/scripts/gate_g1.py"`），
  本联接可安全删除：`rmdir 具身助餐机器人\repo`（rmdir 只删联接本身，不动真实仓库），
  随后可删整个 `具身助餐机器人` 目录（内含本说明）。
- 更彻底的整改：把该工作流草稿迁到正确项目键 `具身助餐机器人\plan\.zcode` 下。
