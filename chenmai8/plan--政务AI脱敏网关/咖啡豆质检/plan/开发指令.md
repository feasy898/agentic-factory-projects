## 1. MVP 范围（10 天）

**做**：
1. 合成整盘图引擎（差异化核心，做扎实）。
2. 全链路：整盘图 → 逐粒分割 → ArUco 坐标变换 → 上下匈牙利配对 → 每粒取最严重缺陷 → 计量（毫米标定、目数分布、色差、估重）→ YAML 标准引擎（CQI Fine Robusta / NY/T 604 / DB46/T 642 三套配置）→ 中英越三语质量护照（二维码验真）→ 溯因智能体（模板实现保底 + LLM API 抽象）。
3. Web/API 壳（FastAPI + 单页演示 UI）。
4. 真硬件链路（相机到货后）：双面拍摄台 + 标定 + 真实豆盘全流程一遍。
5. 评测：3–5 份本地样品对比人工用时与结果一致率；合成图上 oracle 管线 vs 经典管线一致率。

**不做（延后）**：模型训练（training-plan.md）、RK3588 部署、投影 AR 指认（留接口）、区块链上链（只留哈希字段）、quaker 熟豆检测、机械臂。

**没有相机硬件前能演示什么（必须满足）**：合成整盘图上跑通上述 1–3 全链路，产出真实的三语质量护照 HTML + 二维码，全程 CPU。这是 10-08 前演示视频的主体素材。

## 3. 冻结契约（M1，v1.0，改动需规划 agent 批准）

统一缺陷类别体系（内部 `defect-taxonomy.yaml`，含三语名、主/次要归属、严重度默认序）：

```
主缺陷(-primary): black(黑豆) mold(霉豆) sour(酸豆) insect(虫蛀) dried(干瘪/僵豆)
次缺陷(secondary): broken(破碎) brocade(花脸) shell(贝壳豆) elephant(象豆)
                  peaberry(_peaberry 计量不计缺陷，标注保留) immature(未熟) faded(褪色/白化)
normal(好豆)
```

与上游 12 类（MDPI 数据集：normal + sour, brocade, peaberry, shell, elephant, frozen, black_ear, broken, dry, triangle, black）建立映射表：`frozen→dried, black_ear→black(注:黑耳按原文归主缺陷), triangle→peaberry(三角豆=胡椒粒豆), dry→dried`；USK 4 类（peaberry/longberry/premium/defect）只做素材粒型参考，`defect` 粗标不进训练映射。

### 3.1 核心 schema（`beaneye/schemas.py`，Pydantic v2，全部带 `to_json/from_json`）

```python
class BeanMask(BaseModel):
    mask_id: str                 # 面内唯一, 如 "top_017"
    side: Literal["top","bottom"]
    polygon: list[list[float]]   # 盘面坐标系 mm（M3 变换后）; [x,y] 外轮廓
    bbox_mm: tuple[float,float,float,float]  # x0,y0,x1,y1 mm
    area_mm2: float
    centroid_mm: tuple[float,float]
    source: Literal["oracle","classic","nn"]
    conf: float = 1.0            # classic/nn 0-1; oracle=1.0

class SegResult(BaseModel):
    scan_id: str
    side: Literal["top","bottom"]
    masks: list[BeanMask]
    runtime_s: float

class BeanObservation(BaseModel):
    obs_id: str                  # = mask_id
    side: Literal["top","bottom"]
    defect: str                  # taxonomy key, "normal" 无缺陷
    defect_conf: float
    severity_rank: int           # 0=normal 越大越严重, 取自 taxonomy/标准YAML
    crop_path: str               # 掩码裁剪 RGBA PNG 证据
    mask: BeanMask
    color_lab: tuple[float,float,float]      # 掩码内均值 L*a*b*(0-255标度注明)
    eq_diameter_mm: float

class PairedBean(BaseModel):
    bean_id: str                 # "b0001"
    top: BeanObservation | None
    bottom: BeanObservation | None
    pairing_cost: float          # mm 距离; 单面= -1
    worst_side: Literal["top","bottom","both","none"]
    final_defect: str            # 两面中 severity_rank 最高者; 同级取 conf 高
    final_severity_rank: int

class TrayScan(BaseModel):
    scan_id: str
    sample_id: str
    tray_id: str
    top_image: str; bottom_image: str        # 相对路径
    calibration: CalibResult | None          # M3 输出
    captured_at: str                         # ISO8601
    source: Literal["mock","usb","synth"]

class CalibResult(BaseModel):
    px_per_mm: float
    H_top: list[list[float]]     # 3x3 单应: 原图px → 盘面mm
    H_bottom: list[list[float]]
    marker_ids: list[int]        # 期望 [0,1,2,3] 四角
    reproj_err_px: float

class Measurements(BaseModel):
    bean_count: int
    sieve_hist: dict[str,int]            # {"16":320,"15":80,...} 目数→粒数
    sieve_pass: bool | None              # 对照标准
    eq_diameter_mm_stats: StatsSummary   # min/max/mean/median
    color_lab_mean: tuple[float,float,float]
    delta_e_mean: float                  # vs 标准YAML的 reference_lab
    delta_e_hist: dict[str,int]          # 分桶 ["0-2","2-4",...]
    est_weight_g: float; weight_model: str   # "area_linear:v1"

class GradingDecision(BaseModel):
    standard_id: str                      # cqi_fine_robusta | nyt_604 | db46_t642
    grade: str                            # 如 "Fine" / "一级" / "合格"
    passed: bool
    primary_count: int; secondary_count: int
    defect_counts: dict[str,int]          # taxonomy key → 粒数(每粒只计一次)
    reasons: list[str]                    # 人读判定理由(三语模板键)
    standard_yaml_sha: str

class BatchResult(BaseModel):
    result_id: str                        # uuid4
    sample_id: str
    scan_ids: list[str]
    beans: list[PairedBean]
    measurements: Measurements
    grading: GradingDecision
    agent_report: AgentReport | None
    timings_s: dict[str,float]            # 各阶段耗时
    pipeline_versions: dict[str,str]      # {"segment":"classic","classify":"rules_v0",...}

class AgentReport(BaseModel):
    lang: Literal["zh","en","vi"]
    causes: list[CauseItem]      # {defect, stage(采摘/发酵/干燥/仓储), likelihood, evidence_summary}
    advice: list[str]
    citations: list[str]         # 标准条目号/知识库chunk id
    backend: Literal["template","llm"]

class PassportReport(BaseModel):
    report_id: str               # 与 result_id 绑定
    langs: list[Literal["zh","en","vi"]]
    html_paths: dict[str,str]
    qr_payload: str              # verify URL + report_id + sha256(BatchResult json)
    sha256: str
```

### 3.2 接口 Protocol（模型可替换的关键）

```python
class SegModel(Protocol):
    def predict(self, img_rgb: np.ndarray, scan: TrayScan) -> SegResult: ...
class ClsModel(Protocol):
    def classify(self, crop_rgba: np.ndarray, mask: BeanMask) -> tuple[str,float,int]: ...  # (defect, conf, severity_rank)
class StandardEngine(Protocol):
    def evaluate(self, beans: list[PairedBean], measurements: Measurements) -> GradingDecision: ...
class RootCauseAgent(Protocol):
    def explain(self, result: BatchResult, lang: str) -> AgentReport: ...
class CameraSource(Protocol):
    def capture_pair(self, sample_id: str, tray_id: str) -> TrayScan: ...
```

```yaml

    verified: false
```

## 4. 模块 spec + eval

通用约定：
- 工程根目录 `D:\workspace\澄迈8项目\咖啡豆质检\beaneye\`；venv 在 `.venv\`；所有命令在工程根目录执行。
- 每个模块 = `beaneye/<pkg>/` + `evals/test_<pkg>.py`（pytest）+ 必要的 `evals/smoke_<pkg>.py`。
- **模块验收线 = eval 全绿 + 通过线达成**。子代理完成模块的标志是 eval 脚本真实跑过并输出 PASS 摘要。

### M0 环境与开源组合跑通（scripts/）
- **spec**：`scripts/setup_env.ps1` 建 venv、装 pinned 依赖（requirements.txt，见 §6）；`scripts/oss_smoke.py` 依次验证：① cv2.aruco 渲染并检测 4 个 4x4_50 码→单应矩阵；② RFDETRSegNano（COCO 权重，首次自动下载）对一张测试图推理出框/掩码；③ SAM2 small（HF 下载 `facebook/sam2-hiera-small` 的 `sam2_hiera_small.pt`）对一个豆子 crop 出掩码并保存叠加图；④ segno 生成并（zxing-cpp）解码一个二维码。每步打印 `[OSS-SMOKE] n/4 PASS`。
- **eval**：`python scripts/doctor.py`（检查 Python/依赖/权重/数据集目录，输出 DOCTOR: PASS）+ `python scripts/oss_smoke.py`。
- **通过线**：DOCTOR PASS；OSS-SMOKE 4/4；全程 CPU、Windows 原生（不依赖 WSL/Docker）。

### M1 契约（beaneye/schemas.py, beaneye/taxonomy.py）
- **spec**：§3 全部 schema + 缺陷类别映射表 + fixtures（`evals/fixtures/*.json` 每类一个合法样例）。
- **eval**：`pytest evals/test_schemas.py -q`
- **通过线**：全绿；每 schema 往返序列化无损；非法输入（缺字段/越界）正确抛 ValidationError；fixtures 覆盖 8 个 schema。

### M2 采集（beaneye/acquisition/）
- **spec**：`CameraSource` 两实现：`MockSource`（读目录成对图片+写 manifest.json）与 `UsbSource`（`cv2.VideoCapture(CAP_DSHOW)`，双相机按 `configs/camera.yaml` 设备号抓 3840×2160；对焦/曝光可配；无相机时构造即报错并提示用 Mock）。`SynthSource`（调 M12 直接产 TrayScan）。
- **eval**：`pytest evals/test_acquisition.py -q`；真机冒烟（可选）：`python -m beaneye.acquisition.usb --list-cams`。
- **通过线**：Mock/Synth 产出 TrayScan 通过 M1 校验；双图存在且分辨率一致；`--list-cams` 在无相机时退出码 2 而非 traceback。

### M3 标定与坐标变换（beaneye/calibration/）
- **spec**：`calibrate(img_bgr, cfg) -> CalibResult`：检测 ArUco（`cv2.aruco.Dictionary_get(DICT_4x4_50)`，4 角 id=0..3，打印边长 `marker_mm` 来自 `configs/tray.yaml` 默认 60mm），用 `cv2.findHomography` 求原图 px→盘面 mm（盘面 300×300mm，输出网格 2048²，≈0.147mm/px）；提供 `warp_to_tray()` 与 `px_to_mm()`；<4 码时抛 `CalibrationError`（v1 不做单码姿态兜底，现场摆正即可）。
- **eval**：`pytest evals/test_calibration.py -q`（合成渲染 ArUco 于已知 mm 坐标 + 透视/旋转 ±30°/亮度扰动）。
- **通过线**：marker 中心反投影误差 ≤0.5mm；px_per_mm 相对误差 ≤1%；四角顺序任意摆放仍正确配对；单张 12MP 处理 ≤3s CPU。

### M4 分割（beaneye/segment/）
- **spec**：`SegModel` 三实现：
  - `OracleSeg`：读合成 manifest 的真值掩码（RLE→polygon），conf=1.0。用于下游开发与 e2e 上限对照。
  - `ClassicSeg`：亚克力浅色背景 → LAB 的 b 通道/灰度 Otsu 前景 → 开闭运算 → `cv2.watershed`（以前景距离变换峰值做种子）切粘连粒 → 每连通域一个 BeanMask。参数集中在 `configs/segment.yaml`。
  - `RFDETRSegModel`：包装 rfdetr 包的 RFDETRSegNano/Small；`weights=coco`（smoke 用）或 `weights=<微调后 .pth>`（未来）；预测输出转 BeanMask（掩码→polygon→mm 坐标经 M3）。ONNX 导出脚本 `scripts/export_onnx.py`（失败不阻塞，v1 允许直接 torch CPU 推理）。
- **eval**：`pytest evals/test_segment.py -q`
- **通过线**：Oracle IoU=1.0；Classic 在**稀疏盘（≤150 粒、无粘连）**：粒数误差 ≤5%、平均 IoU ≥0.85、12MP ≤5s；在**稠密盘（250 粒允许粘连）**：粒数误差 ≤25%（明确记录为 NN 模型上线前的已知短板）；RFDETRSegModel(COCO) 在合成盘上跑通且 ≥1 mask、≤60s CPU（无精度线）。

### M5 分类（beaneye/classify/）
- **spec**：`ClsModel` 实现：
  - `RulesV0`：特征 = LAB 均值/分位数、ΔE（对精品参考与对黑豆参考）、面积比（该盘豆面积中位数）、长宽比、圆度、纹理熵、HSV 色相直方峰。规则表（YAML `configs/rules_v0.yaml`）按 taxonomy 输出 `(defect, conf, severity_rank)`；conf=规则命中强度，多规则命中取 severity 高者。规则阈值允许 D7 用本地豆照片回填。
  - `ONNXCls`：占位类，加载 `models/cls.onnx`（未来训练产物），接口已冻结。
  - `RFDETRJoint`：从 RFDETRSegModel 结果直接带出类别（未来），跳过独立分类。
- **eval**：`pytest evals/test_classify.py -q`（从素材库抽 300 粒已知标签单粒 crop 测试）。
- **通过线**：macro-F1 ≥0.60；black、broken 两类 F1 ≥0.75；无崩溃；≤50ms/crop CPU；输出混淆矩阵到 `out/eval/classify_report.json`。

### M6 上下配对（beaneye/pairing/）
- **spec**：输入 top/bottom 两组 BeanObservation；代价矩阵 = 盘面 mm 欧氏距离；门限 `gate_mm=12`（超过视为无配对，置 inf）；`scipy.optimize.linear_sum_assignment` 求解；inf 对不进结果；单面豆保留（worst_side 相应处理）。输出 PairedBean 列表（bean_id 顺序稳定：按 top 质心 x,y 排序）。
- **eval**：`pytest evals/test_pairing.py -q`（合成：200 粒、抖动 σ=3mm、10% 随机丢面、5% 伪观测；另加整体平移 5mm 的标定误差场景）。
- **通过线**：配对 precision ≥0.98、recall ≥0.95（含标定误差场景 ≥0.95）；≤1s CPU；bean_id 稳定可复现（同输入同输出）。

### M7 严重度裁决（beaneye/severity/）
- **spec**：`worst(top,bottom,severity_order) -> (final_defect, worst_side)`：severity_rank 高者胜；平级取 defect_conf 高者并记 worst_side="both"；任一面为 None 取另一面。severity_order 从标准 YAML 读（不同标准可不同）。
- **eval**：`pytest evals/test_severity.py -q`（表驱动 ≥15 用例，含并列/单面/normal vs 缺陷）。
- **通过线**：用例 100% 正确。

### M8 计量（beaneye/metrology/）
- **spec**：`measure(beans, calib, std_yaml) -> Measurements`：
  - 粒径：两面各自等效直径（面积→直径）取均值（单面取该面）；目数 `screen = round(d_mm/25.4*64)`，直方输出；
  - 色差：两面 LAB 均值先合并（severity 高侧权重 0.7），`ΔE76 = ||Lab-Lab_ref||`（v0 明确记录用 CIE76，留 ΔE00 升级位）；
  - 估重：`Σ area_mm2 × g_per_mm2`（系数从标准 YAML/配置读，到货标定后回填）；
  - 筛目/色差对照标准产生 sieve_pass 等布尔。
- **eval**：`pytest evals/test_metrology.py -q`（已知直径的合成圆、已知 LAB 的合成色块、标定砝码 fixture）。
- **通过线**：直径误差 ≤2%；目数 100% 正确；ΔE 与参考实现（手算）偏差 ≤1.0；标定后估重误差 ≤15%；≤2s/盘 CPU。

### M9 标准引擎（beaneye/standards/）
- **spec**：`load_standard(id)` 校验 YAML schema（`verified:false` 收集为 warnings）；`evaluate()`：按 `count_rule` 计数（每粒只计最严重缺陷）、主/次要缺陷分计、逐 grade 判定（阈值全比较含 sieve/color 条件）、生成 reasons（i18n 模板键 + 数值）；输出 GradingDecision（含 standard_yaml_sha256）。未知 standard_id 或 YAML 非法 → 明确异常。
- **eval**：`pytest evals/test_standards.py -q`（表驱动 ≥20 用例：CQI 0主+5次=过、0主+6次=不过、1主=不过；NY/T、DB46 各自阈值用例；verified 标志传递）。
- **通过线**：用例 100% 正确；三套 YAML 全部能加载；错误信息含文件路径与行号。

### M10 质量护照（beaneye/report/）
- **spec**：Jinja2 模板 `report_{zh,en,vi}.html.j2`（A4 打印 CSS）；内容：样品/批次信息、定级结论（大字）、缺陷计数表、目数分布直方（matplotlib 出 PNG，中文字体用黑体/SimHei，注意负号）、色差表、每缺陷豆证据卡（top/bottom crop 并排 + bean_id + 置信度）、溯因建议、页脚标准核对角标（引用 GradingDecision.warnings）、二维码（`segno`，payload=`{verify_base_url}/r/{report_id}|sha256`）。sha256 对 BatchResult 规范化 JSON 计算。
- **eval**：`pytest evals/test_report.py -q`（三语各生成一份；`zxing-cpp` 解码 QR；HTML 用 `xml.dom.minidom` 做良构检查；检查证据卡数量=缺陷豆数）。
- **通过线**：三语文件生成（各 >20KB）；QR 解码回 payload 且 sha256 一致；证据卡无缺图；生成 ≤5s/份。

### M11 溯因智能体（beaneye/agent/）
- **spec**：`TemplateAgent`：离线规则表 `configs/rootcause.yaml`（缺陷→环节（采摘/发酵/干燥/仓储/脱壳）→ likelihood 先验 → 三语建议文本 → 引用标准条目/知识库 chunk）；输出三语 AgentReport。`LLMAgent`：OpenAI 兼容 ChatCompletions 客户端，`BEANEYE_LLM_BASE_URL/KEY/MODEL` 环境变量配置；system prompt 内嵌标准 YAML 摘要 + BatchResult 统计 JSON + 知识库检索片段；输出强制 JSON（response_format=json_object，不支持则解析兜底）；**任何失败自动降级 TemplateAgent 并在 report.backend 标注**。知识库（可选增强）：`beaneye/kb/` 把三套标准+NY/T 1519 缺陷图说明+DB46/T 278 初加工标准文本切块，`bge-m3`（sentence-transformers，CPU，模型缓存 `models/bge-m3/`）+ Chroma 持久化 `data/kb_chroma/`；嵌入过慢或不可用时降级 rank_bm25。LLM 与 KB 都不影响主链路（主链路评测不依赖网络）。
- **eval**：`pytest evals/test_agent.py -q`（Template 三语全缺陷类覆盖；LLM 用 httpx MockTransport 返回 canned 响应验证解析/降级路径）。
- **通过线**：TemplateAgent ≤100ms、三语无缺键；LLMAgent mock 全绿；断网时 e2e 仍全绿。

### M12 合成数据引擎（beaneye/synth/）——差异化核心，做扎实
- **spec**：
  - **素材库构建** `python -m beaneye.synth.build_materials --src data/datasets/defectos_cafe_verde --out data/materials/dcv/`：读 Roboflow COCO-segmentation 导出的多边形掩码，按类别抽出单粒 RGBA（去背、按掩码羽化 1px、统一按其 mm 直径记录 scale——DCV 无绝对毫米标，默认按罗豆先验 6.0mm 中位直径设定 per-class scale 并在 materials.json 标注 `assumed_mm`）；USK-COFFEE 无掩码，用 SAM2 small 逐图自动掩码后同流程（`--src usk` 路径，生成 `data/materials/usk/`）。素材条目：{material_id, source, defect_class, rgba_path, width_mm, quality_flags}。每类 ≥60 粒为佳，<20 粒该类标 WARN。
  - **铺盘合成器** `beaneye/synth/compose.py`：参数（`configs/synth.yaml`）：n_beans 范围/类先验（可指定"缺陷率 8%"）、旋转、缩放抖动 ±10%、允许粘连（粘连率控制 0-40%）、投影阴影（alpha 偏移模糊）、背景（实拍亚克力空盘照 `data/backgrounds/` 或渲染纯色+噪声）、全局光照扰动（亮度/对比度/gamma，Albumentations 2.0.8）、运动模糊/噪点开关。
  - **成对生成**：同一布局生成 top 与 bottom 两图——bottom 用素材池镜像（另一面不可知，就重新采样同 mm 同类的另一粒，配对真值仍成立：两图共享同一布局坐标与 bean_id）；真值 manifest 记录每粒 {bean_id, class_top, class_bottom, poly_mm, eq_diameter_mm}。
  - **输出**：`data/synth/<batch>/top_0001.png(2048²)` + `bottom_0001.png` + `labels_0001.json`（M1 兼容 + COCO RLE）+ batch index。种子可复现。
- **eval**：`pytest evals/test_synth.py -q`
- **通过线**：固定种子 5 盘可复现（像素级一致）；真值与渲染 alpha 的重合 IoU=1.0；mm 尺寸与素材规格偏差 ≤0.1mm；吞吐 ≥0.5 盘/s（200 粒，CPU）；labels JSON 过 M1 校验。

### M13 应用与 API（beaneye/app/）
- **spec**：FastAPI：`POST /api/v1/scans`（multipart 两图或 `{"synth": {...}}`）→ `{job_id}`；`GET /api/v1/jobs/{id}`（状态）；`GET /api/v1/results/{id}`（BatchResult JSON）；`GET /api/v1/results/{id}/passport?lang=zh`（HTML）；`GET /api/v1/standards`；进程内任务队列（ThreadPoolExecutor）。演示 UI：`/demo` 单页（Gradio 挂载或纯 HTML+JS：上传两图→轮询→渲染报告 iframe）。
- **eval**：`pytest evals/test_app.py -q`（httpx TestClient 全流程）。
- **通过线**：全端点 200 且 schema 合法；synth 全流程请求 150 粒盘 ≤60s 返回结果（CPU 实测记录，不作硬断言上限时允许 skip）；断网可用。

### M14 端到端演示与评测（scripts/e2e_demo.py）
- **spec**：`python scripts/e2e_demo.py --trays 3 --beans 120 250 --segment classic --classify rules_v0 --standard cqi_fine_robusta --langs zh,en,vi --out out/e2e`：合成→全链路→3 份三语护照 + `e2e_summary.json`（每阶段耗时、oracle-vs-classic 一致率、缺陷计数表）。`--segment oracle` 跑对照上限。真硬件模式 `--source scan` 走 M2 实拍。
- **eval**：`pytest evals/test_e2e.py -q`（pytest 内 subprocess 跑 e2e_demo 小参数版）。
- **通过线**：退出码 0；护照文件存在且 QR 可解码；oracle 管线缺陷计数与真值**完全一致**（链路自洽性）；classic 管线与 oracle 的逐豆标签一致率 ≥0.55（记录值，视频里如实呈现"AI 初检+人工复核"定位）；3 盘总时长 ≤10min CPU。
