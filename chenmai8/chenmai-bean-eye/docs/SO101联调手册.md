## 4. 外参三点标定（相机 → 桌面毫米）

目标：得到「图像 px → 臂基座桌面 mm」映射。两条路任选（推荐 A+B 互校）：

**A. ArUco 路线（复用质检线标定）**
1. 托盘四角码就位（质检线同款托盘与布局），拍一帧；
2. `.venv` 跑 `beaneye.calibration.calibrate(img)` 得 `SingleCalib.H`
   （`beaneye.calibration` 无 CLI——取帧+标定的可照抄片段见
   `docs/交接-实时标注与SO101联调.md` §④.4）；
3. 标安装外参：托盘上放一粒已知桌面坐标的标记豆（例如用量块/尺子量出
  「托盘左上角码中心 + 已知臂基座位置」推算），把偏差回填
  `configs/sort.yaml → extrinsic.offset_mm / yaw_deg`；
4. 验证：画面上任取一豆，`FrameToTable.px_to_table_mm` 输出 vs 尺子实测 ≤3mm。

**B. 纯三点仿射路线（不依赖托盘码，分拣台无码时用）**
1. 桌面/托盘上画/放 **3 个非共线**标记点，尺子量出各自桌面 mm 坐标（臂基座为原点）；
2. 相机拍一帧，手动读出 3 点像素坐标；
3. `beaneye.sort.frame.solve_affine(src_px, dst_table_mm)` 得 `Affine2D`，
   `fit_residual(...)` 应 ≤2mm，超了重选点；
4. 检验点（第 4 点，不参与求解）误差 ≤3mm 方可用。

- [ ] 标定结果（extrinsic 或三点仿射）回填/存档，写进当日 worklog

## 7. 常见问题（现场速查）

| 症状 | 首查 | 处置 |
|---|---|---|
| `connect()` 抛 RuntimeError 附安装指引 | 没装 lerobot / 用错解释器 | 在 `.venv-arm` 里跑；核对 §2 |
| 总线扫描不到舵机 | COM 号错 / TX-RX 接反 / 供电不足 | 设备管理器核对；量 5V 电压；逐段拔插定位断点 |
| 扫描到 ID 少于 6 | 舵机 ID 冲突/损坏 | 单舵机直连核对 ID；FD 软件改号 |
| 运动中途臂发抖、报运动超时 | 供电跌落（多舵机同动电流峰值） | 换 5V/6A 电源；限速再收紧；错峰（本线动作为串行，一般不会） |
| 到位但 `move_to` 判超时 | `arrival_tol_deg` 过严 / 换算错 | 放宽容差到 5° 试；回填 `raw_per_deg` |
| 抓取打滑/压碎豆 | `pick_z_mm` / 夹爪角不对 | §5 回填；夹紧角宁松勿紧（掉豆重抓优于碎豆） |
| 画面豆位置和臂抓取位置系统性偏几 mm | 外参残余偏差 | 用第 4 节检验点重标 `extrinsic`（只改 `offset_mm` 通常即可） |
| 全部目标 skipped | 托盘摆放超工作空间 | 看 Session 事件里 skip 原因；挪托盘或改 `workspace` |
