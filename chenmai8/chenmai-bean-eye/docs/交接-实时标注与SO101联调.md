## ③ 明晨摄像头实测清单（两路，各约 10 分钟）

前提：`.venv` 在仓库根（今晚全量 649 passed 即其上实测）；桌面上放质检线同款四角
ArUco 码托盘（码图可用 `scripts/make_aruco.py` 重打印），旁边一把直尺做毫米核对。

### A. USB 相机直插

- [ ] 相机 USB 直插本机，关闭可能占用相机的其他软件
- [ ] 确认设备号：`python -c "import cv2; c=cv2.VideoCapture(0); print(c.isOpened())"` → True
      （False 则依次试 index 1/2）
- [ ] 实测命令：
      `.venv\Scripts\python.exe scripts\demo_realtime.py --source usb --index 0 --width 1280 --height 720`
- [ ] **预期现象**：预览窗实时出现人脸/桌面画面并被逐帧着色标注；HUD 的 FPS 稳定显示
      （引擎处理帧 EMA ≥5 为达标口径）；**四角 ArUco 入画后** HUD 标定状态切到毫米模式，
      豆粒标签显示真毫米尺寸——拿直尺量一粒豆对比，偏差应在 ±10% 内；**无码时**标签
      诚实显示「伪毫米」
- [ ] 按 q 退出，记录：实测 FPS、mm 偏差、存图清单（`out\realtime_demo\`）
- [ ] 异常排查：黑屏/打不开 → 换 `--index`；帧率过低 → 加 `--downscale 0.6` 或 `--skip 1`
      （降耗旋钮，画面仍逐帧但隔帧处理）

### B. 手机 IP 推流（App 提供 MJPEG 流）

- [ ] 手机装任一可输出 **MJPEG** 流的 App（如 Android「IP Webcam」，其视频地址为
      `http://<手机IP>:8080/video`），手机与电脑同一局域网
- [ ] 先用电脑浏览器开该 URL 确认能直接看到流动画面（打不开 = 网络/防火墙问题，先解决）
- [ ] 实测命令：
      `.venv\Scripts\python.exe scripts\demo_realtime.py --source ip --url http://<手机IP>:8080/video`
- [ ] **预期现象**：与 USB 路一致（着色标注 + HUD + 图例 + ArUco 毫米）；关键差异是
      **延迟**——IPCameraSource 每帧先经 `drain_and_retrieve` 丢积压只留最新
      （`beaneye/realtime/sources.py:147`），网速抖动时表现应为「FPS 下降但延迟不持续增大」；
      手在镜头前快速挥动，画面滞后应停在约 1-2 帧内
- [ ] Web 形态抽查：`http://127.0.0.1:8600/live/stream?source=ip&url=http%3A%2F%2F<手机IP>%3A8080%2Fvideo&max_frames=5`
      （浏览器应看到 MJPEG 逐帧刷新；故意填错 URL 应得 503 + 排查提示 JSON）
- [ ] 两路结果回填当日 worklog（FPS / mm 偏差 / 异常）；`out\` 产物留档不入库

## ④ SO-101 上电联调步骤（细节以 [SO101联调手册.md](SO101联调手册.md) 为权威）

今晚 Mock 链路已全绿；以下为**真机增量**执行顺序（手册 §1–§6 逐一对应）：

1. **接线（断电）**〔手册 §1〕：6 个 Feetech STS3215 按 ID 1..6 菊花链（ID1=基座→ID6=夹爪）；
   5V/≥4A 电源接主控板；USB-UART 接电脑后在设备管理器记下 COM 号，
   回填 `configs/sort.yaml → so101.port`。注意：v1 急停 = 软件急停 + 拔电源，**无硬件急停回路**，
   人员随时能拍电源开关。
2. **建独立环境**〔手册 §2〕：
   `python -m venv .venv-arm` → `.venv-arm\Scripts\pip install -r requirements-arm.txt`
   （国内镜像可加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）。装通后 `pip freeze`
   回填钉版；核对 `.venv` 里**没有** lerobot（不污染钉版核心）。
3. **适配器 connect 自检**〔手册 §3〕：`.venv-arm` 里总线扫描应枚举到 ID 1..6；
   手扳基座到已知角度，`SO101Arm.joint_angles_deg()` 读数应在 ±3° 内，不对则回填
   `center_raw/raw_per_deg`；手册点名的两处接口签名（`FeetechMotorsBus` 构造、
   read/write 寄存器映射）是今晚离线未能验证的，装机必做。
4. **外参标定（相机→臂基座桌面毫米）**〔手册 §4〕：推荐 ArUco 路线 + 三点仿射互校——
   托盘码就位拍一帧，`.venv` 跑 `beaneye.calibration` 得 H；再在托盘放 3 个非共线
   已知桌面坐标标记点，`beaneye.sort.frame.solve_affine(src_px, dst_table_mm)` 求解，
   `fit_residual` ≤2mm、第 4 检验点 ≤3mm 方可用；结果回填 `configs/sort.yaml` 外参节
   （今晚全零占位）。
5. **空载慢速试跑**〔手册 §5〕：先把 `configs/sort.yaml → speeds` 收紧
   （max 40 / travel 30 / descend 15），`connect()+home()` → 单点 `move_to(120, 0, 40, speed=30)`
   → 夹爪开合回填 `gripper_open_deg/closed_deg` → 2-3 粒假豆小循环 → 确认无异响/堵转后
   逐级放开限速。
6. **急停演练**〔手册 §6〕：作业中途调 `session.estop()`——臂应立刻下力矩冻结、Session
   转 `estopped`、后续指令被拒（`SessionEstopError` 语义）且事件日志含 `estop`；
   演练「徒手搬回安全位 → 新建 Session → connect+home」的恢复流程；人手进工作半径必须先急停。
7. **收工**〔手册 §8〕：回填全部「明日实测」占位值、`requirements-arm.txt` 钉版、
   真机一盘的前后对比 PNG + 轨迹 JSON 留档 `out\sort_sim\`、全量测试复跑确认零回归。

## ⑤ 风险与未验证项（真机未测，逐条如实）

1. **实时线从未接过真实摄像头**：今晚全部实测在合成源上。USB 相机的设备号协商、分辨率/
   四镖格式（MJPG vs YUY2）实际帧率、IP App 的 MJPEG 兼容性，均待明晨 §3 首测。
2. **FPS 数字口径**：5.91 EMA 是合成源 720p 固定负载的处理帧口径；真实摄像头自动曝光/
   低光下可能显著低于此数。消费循环 3.64 FPS 的 elapsed 含合成盘预合成热身，勿对外引用。
3. **so101.py 真机路径（transport=None）整段未实测**（今晚无硬件）：
   `FeetechMotorsBus` 新旧构造签名兜底、`read_positions/write_goal_positions/set_goal_speed`
   到 lerobot 寄存器的映射、舵机 raw↔deg 换算（`center_raw/raw_per_deg`）、基座偏航 +
   二连杆竖直工具 IK v0 的连杆几何——**全部为占位默认值**，上电后按手册 §3 逐项核对回填，
   任何直接带豆运行都是禁忌。
4. **`configs/sort.yaml` 外参与几何**：extrinsic 全零占位、workspace 包络与 pick 高度为
   内收默认值，均以「明日实测」标注，待 §4 标定与 §5 试跑回填。
5. **Mock 数字≠真机节拍**：43 步 / 21710mm / 7.3s 是 `--time-scale 1000` 仿真口径，
   真机按限速（默认 80mm/s 档）推算约慢 3 个量级，演示时如实说明。
6. **手机 IP 推流的协议前提**：只支持 MJPEG 流 URL；若 App 只给 H.264/FLV 地址会打不开
   （AcquisitionError→503），需换 App 的 MJPEG 端点，代码不做转码。
7. **训练线既有偏差不变**：NN 栈真实模式 API 仍待 GPU 机 `--cpu-smoke`/`--smoke-train`
   核对；mask AP50 为自实现口径（未对齐 pycocotools）。
8. **测试偶发已知项**：`tests/test_realtime_sources.py` 与 `tests/test_report.py` 在全量
   负载下曾各偶发 1 次失败（隔离复跑分别 9/9 与 27/27 全绿，且均不 import `beaneye.sort`）；
   若复现先隔离复跑再排查负载耦合。接手时 sources 线那 1 个失败已定位为该线遗留测试自身
   两处 bug（脚本时钟未按每次迭代两次读钟给增量、`_FakeCap` 违反 cv2 `grab→retrieve`
   配对语义），已修复；`--save-frames 3` 实存 2 张为计数口径（原图+标注图并计），简报
   允许 2-3 张，非丢帧。
9. **生豆自采链（C3-A5）**：继续物理等待 WAITING_EVENT，到货前不占用会话。
