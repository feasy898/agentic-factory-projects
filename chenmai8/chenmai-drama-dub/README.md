# 一剧N国 · 短剧出海本地化引擎

输入一集带中文硬字幕的竖屏短剧，输出英语、西语、阿语等市场版本：保留原演员音色与情绪的配音、台词时长与原片对齐、正脸近景口型同步、中文硬字幕擦干净并重渲染目标语字幕、按目标市场出合规风险报告并自动加 AI 标识。同一引擎亦可处理游戏 PV/CG 与文旅宣传片。

**核心能力**

- 音频链路：人声/背景分离、识别 + 逐字对齐、说话人区分与角色音色库绑定
- 翻译：整集上下文 + 每句时长预算；时长可控译法（超长自动换短译法）
- 配音：音色参考与情绪参考分离，哭腔怒吼情绪迁移；语速微调 0.9–1.1x
- 口型：按镜头分流，仅正脸近景做口型同步
- 字幕：硬字幕抽取与擦除（避开 AI 标识区）、目标语渲染（含阿语 RTL）
- 合规：各市场规则包（YAML）、关键帧与台词预检、显式水印 + 隐式元数据 AI 标识 + 音频水印
- 审校台：逐句修改、单句重生成、术语表管理，导出 MP4 / 字幕 / 合规报告

**仓库结构（建设中）**

```
docs/      架构、数据 schema、模块契约、spec + eval
pipeline/  管线编排与任务队列（音频/翻译/配音/口型/字幕/合规）
dubmt/     时长可控翻译模型（数据合成与训练脚本）
review/    Web 审校台
```

> 详细模块规格与验收标准见 `docs/`，逐模块 spec+eval 驱动开发。
