## 一句话核心思想

**"前处理 / 理解"彻底分工**：纯图像算法（零模型调用）把一段视频压缩成少数几张"多模态大模型读得清"的关键帧总览图，让模型按时间顺序"看完"全片；语义理解本身完全交给具备视觉能力的多模态 LLM。它不识别任何内容——不接多模态模型，它产出的只是一堆图片。

## 桥接机制的三支柱

### 1. 变化驱动选帧（解决"帧太多"）

- **双角度差异检测**：每帧缩成 200px 宽灰度图与上一帧求差异，同时看两个角度取较大值——
  ① 全局平均差异（抓转场/换色）；② 8×8 分块中"变化最剧烈那一块"的差异（抓角落小动作。
  实测：只盯全局平均时角落小移动被稀释到 0.004（与噪声同量级），分块能拿到 0.06）。
- **自适应阈值，免调参**：视频大部分时间静止，相邻帧差异的**中位数≈底噪**；
  `阈值 = 底噪中位数 × noise-k(默认4.0)`，夹在 `[0.008, 0.08]`。实拍底噪≈0.011 → 阈值≈0.043（不被噪点骗）；
  合成动画底噪≈0 → 阈值=0.008（很敏感）。
- **"等它变完"选帧**：画面变化开始不急着选，等变化结束后的**稳定帧**才入选——避免抽到元素
  尚未出现/已消失的空白中间态。持续变化（运镜/长动效）每 `--motion-time`(1.5s) 强制补一张；
  相邻关键帧至少 `--min-time`(0.3s) 防抖。
- **抽稀优先于调阈值**：帧太多时用 `--max-frames`/`--sheet-max-cells` 在已选好的好帧里均匀抽稀，
  而不是调高阈值——阈值一高，淡入淡出这类渐进变化会中途被误判"已结束"，反而抽出空白帧
  （README 实测：0.03 阈值抽 19 帧一多半空白；0.008+抽稀到 32 格帧帧完整）。

### 2. 为"模型的眼睛"调优呈现（解决"帧太糊"）

- 第一性约束：读图工具把每张图整体压到**长边约 1080–1568px** 再交给模型 →
  **每格能分到多少像素只取决于一张图里有多少格**，与图做多大基本无关。
  实测 4m42s 讲解视频：12 格/张 1600px → 每格~380px 小字可读✅；40 格塞一张 → ~180px 全糊且 9597px 被拒收❌。
- 三条硬规则：**每张 ≤12 格（最多16）、列数 ≤4、图宽 ≤2400px（1600 为安全+够清落点）**。
  帧多就自动按时序切成多张（每张格数差 ≤1，清晰度一致）；超过 `sheet-max-sheets` 上限按时间均匀抽稀。
- 图面零元数据：只有画面网格 + 每格下方 `#序号 时间戳`；尺寸/时长/帧率全进 `keyframes.json`，
  省下的高度全留给格子。
- 拼图 LANCZOS 重采样 + JPEG 4:4:4 不抽样色度，保证格内文字不糊。

### 3. 工程形态：单文件、双入口、技能化

- `scripts/extract_keyframes.py` 单文件 1029 行，**CLI 与 import 双入口**（`meta = extract_keyframes(...)` 返回 dict）。
- 依赖极薄：Python 3.8+ / numpy / Pillow / 系统 ffmpeg（两次解码：分析一遍 + 命中帧导出一遍；
  刻意**不用** ffmpeg `select='eq(n,..)+'` 滤镜——上百关键帧会超 ffmpeg 表达式解析上限，改 Python 侧按帧号筛选）。
- 输出三件：`overview*.jpg`（时序总览，先读这张）、`frames/kf_NNN_t.jpg`（单帧原图，按需补细节）、
  `keyframes.json`（元数据+每帧时间戳+diff 分值）。
- `SKILL.md` 把链路固化成 Agent Skill，三条调用约定：**隐式调用铁律**（见到视频文件必先抽帧再答，
  禁止凭文件名猜）、**固定档位**（`--cols 3 --sheet-max-cells 12 --sheet-width 1600`）、
  **逐张读完**（overviews 按顺序全读，小字不清读单帧补，不重跑脚本）。
- 性能（README 自报，declared）：3 分钟 1080p 全流程 ≈22s；4m42s 推荐档位 ≈45s。

## 明确边界（作者自述）

- **只有画面线，没有音频线**——"人声说了什么"不覆盖，需另行 ASR，不得假装从画面"听"到。
- 本身不下任何语义结论；产出=图+JSON。
- 只抽帧不改视频，不为"看得清"转码/裁剪原始素材。

## 对我方最有迁移价值的三个想法（与授权无关的思想层）

1. **"中位数=底噪"的自适应阈值**——免标定的变化检测，可直接用于任何"找画面变化点"的场景。
2. **"每格像素数由格数决定"的呈现预算模型**——凡是要给多模态模型喂拼图的场景都适用，
   12 格/1600px 是现成安全档位。
3. **"等它变完"的稳定帧选择**——对字幕淡入淡出密集的短剧素材尤其重要（抽到字幕显示完整的帧）。
