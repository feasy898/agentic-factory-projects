# TASK: zcode-skill-factory —— skill 工厂课堂产线（owner 口径：带学员走通真实交付）

> 任务卡版本 v1.1（2026-10-01 公开仓改写）｜状态载体：`skillfactory/REGISTRY.md`（资产级权威）+ 本文件（任务级）
> owner 口径（2026-10-01）：**具体研究内容不重要，重要的是 skill 工厂**——面向大量想学 AI 的人，教学重点不是讲什么内容，而是带着学员通过 skill、MCP 等 agent 能力支撑品直接走一遍「获得真实交付」的过程；课堂高度确定性；这是当前整个业务的收费逻辑。

## 1. 目标

把 skillfactory 从「资产生产线」升级为「课堂产线」：

- 每个入册资产的准入以「能否支撑学员在课堂中**确定性地走通一次真实交付**」为最终判据；
- 产线持续产出 v0.2 达标资产（P 线）；
- 完成首批课堂交付物：走查脚本 + 学员手册 + 彩排通过（K 线）；
- 三个达标 dist 包完成发布闭环（唯一人工批准点）。

**与旧线的拆分**：研究线（ZCode 平台逆向/市场调研）验收已达成，**关闭归档**，不再占用会话；其产物（zctl、调研报告）降级为输入资产。

## 2. 验收标准（可判定）

### 2.0 产线底线（每批资产准入必过）

| # | 断言 | 判定 |
|---|---|---|
| G0-1 | 确定性评测过门 | `python skillfactory/v5/assets/<asset>/eval/runner.py <被测产物> <oracle>` → exit 0（输出无时间戳、可复跑对账） |
| G0-2 | 红路 fail-closed | 同命令对空目录 → exit 1（红路永远不许修成 exit 0；红路验证纳入每批评测） |

| G0-4 | 变更留痕 | 每批收口 git 化（提交行含资产 id/门数/判定），worklog 一行一轮 |

### 2.1 课堂交付层（K 线——「课堂高度确定性」的可判定物）

| # | 断言 | 判定 |
|---|---|---|
| K-1 | 课程走查脚本成文 | `skillfactory/classroom/walkthrough.md`：从零环境到「学员产出一份真实交付物」≥10 步，每步含「操作 + 验证命令 + 预期输出特征」；引用的 skill/MCP 逐个给出 REGISTRY 行号 |
| K-2 | 学员手册成文 | `skillfactory/classroom/handbook.md`：目标交付物定义/前置环境/逐步指引/常见卡点与自检；不含必须人工兜底的步骤 |
| K-3 | **彩排通过（核心判定物）** | 零上下文「学员」角色（独立会话，**只发手册+走查脚本**）在时间盒（建议 ≤0.5 天）内完整走通：`skillfactory/classroom/rehearsal/` 留档每步 PASS 行 + 最终交付物 + 缺陷清单；走不通 = 课堂不合格，修手册重排 |

## 5. 会话分解与委托要点

| 会话类型 | 职能 | 输入 | 输出 | 禁止 |
|---|---|---|---|---|
| S-执行（worker-A 式） | 资产生产/终门迭代 | EVAL-SPEC + 模板契约 + 缺陷清单 | 产物 + eval 通过 + worklog 行 | 不自评达标；不改评测器与阈值 |
| S-验收（worker-B 式） | 评估登记/复跑对账 | G0 命令清单 | eval-records 判定行 + REGISTRY 行更新 | 不信任自报；与执行不同会话 |
| S-评审（judge 式） | 盲评/裁决 | 双臂盲态材料 | 裁决回写 + 台账行 | 与执行/验收隔离；先裁后改 |
| S-课程 | 走查脚本/手册/资产清单 | 教学目标 + 候选资产 REGISTRY 行 | K-1/K-2/K-4 产物 | 不臆造未入册资产；不写无法验证的步骤 |
| S-彩排 | 零上下文学员走查 | **仅**手册 + 走查脚本 | K-3 彩排记录 + 缺陷清单 + 交付物 | **禁读**工厂线代码/REGISTRY/其余工作区（盲态）；卡点如实记录不自行绕过 |
| S-人审 | K-5 发布批准 | dist 包摘要 + 三齐证据 + 彩排结论 | evidence/publish-approval.md | 其他角色不可代签 |

**红线**：禁止改评测阈值/判据凑绿（红路必须保持 exit 1——全卡信用底线）；对外发布必须人工批准；密钥不入仓；课堂承诺边界 = 只承诺「学员走通真实交付的过程」，不承诺任何就业/收益结果；参与迭代的样本与独立验证样本分离（盲评加厚用新鲜样本）。

**方法论资产（可迁移）**：skill 资产准入三齐门；「课堂走查彩排法」（零上下文角色 + 时间盒 + 逐步验证 = 交付过程确定性的判定法——直接服务收费业务）；AUTONOMY.md 授权文档范本。
