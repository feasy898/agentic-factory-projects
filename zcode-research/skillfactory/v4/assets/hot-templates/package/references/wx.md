# references/wx.md — 公众号文章模板与要素规范

结构名：**引子 + 三段论 + 金句收尾**（5 要素，id 顺序冻结，模板版本 1.0）。

## 要素清单

| order | id | name | 冻结标记 | 开放槽位（token 冻结） |
|---|---|---|---|---|
| 1 | `lead_in` | 引子 | 含主题 | 1 处：`用一个具体场景/对话/新闻切入，150字左右` |
| 2 | `thesis_what` | 三段论·一（是什么） | text 以「一、是什么」开头 | 2 处：`常见误解` + `一句话给出你的定义` |
| 3 | `thesis_why` | 三段论·二（为什么） | text 以「二、为什么」开头 | 3 处：`根因1`、`根因2`、`根因3` |
| 4 | `thesis_how` | 三段论·三（怎么办） | text 以「三、怎么办\n落到操作层面，给你三个抓手：」起；三个抓手行 `N. <卖点或占位>——…` | 3 处**同名**：`展开：具体做法+一个例子`（去重后 open_placeholders 仅 1 个 token）；三个卖点槽位**同居此要素** |
| 5 | `golden_ending` | 金句收尾 | text 结构 `「<主题>这件事，…」\n共勉。` | 1 处：`金句主体——句式建议：真正的…不是靠…，而是靠…` |

- **卖点槽位注意**：wx 的三个卖点槽位不在三个 thesis 要素里分开，而是全部同居
  `thesis_how`（抓手 1/2/3）；缺失/空白 → 对应 `【占位:价值点N】`；
  第 4 条起保序记入 `structure.json.points_unused`。
- **`filled_from_input` 注意**：`topic` 在 lead_in / thesis_what / thesis_why / golden_ending
  **四个要素各记一次**；thesis_how 记 `point#1..3`（仅已填槽位）。
  因此满 3 卖点时 `total_filled_from_input=7`、0 卖点时 `=4`（总 open 恒 10）。
- 平台名（platform_name / 骨架.md 首行）：**公众号文章**。

## 写法方法（扩写成文）

1. 引子：从一个具体场景切入，30 字内让读者对号入座，落点引出主题。
2. 是什么：先给一句话定义，再点破一个普遍误解（"很多人以为…其实…"）。
3. 为什么：三个根因层层递进，每个根因配一个生活化例子；根因槽位按"机制"而非"现象"补写。
4. 怎么办：三个抓手逐一对应三个根因，每个抓手给最小启动动作；抓手细节槽位补"第一步做什么"。
5. 金句收尾：金句 + 共勉收束，触发转发与在看；金句槽位补一句可摘抄的观点句。

## 平台红线

- 三段论标记（「一、是什么」「二、为什么」「三、怎么办」）为结构冻结，扩写时保留在段首。
- 公众号是"读"的文体：段落 ≤ 5 行，多分段，禁口语腔（"家人们"式）。
- 金句收尾必含「共勉」，禁鸡汤堆砌。
- 禁改动冻结标记与要素 id/顺序；`【占位:…】` 槽位扩写前保持原样。
