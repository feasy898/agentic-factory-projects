## 0. 三层总览：一张表看全

| 层 | 一句话 | 承接研究报告的什么 | 承接 skillfactory 的什么 | 收入形态 | 对应客户分级 |
|---|---|---|---|---|---|
| **免费层** | 别人收费教的（3980–7980 差评带训练营里教的「工具怎么用」），我们做成免装可用的单点资产免费送 | 5 门课各自的「免费单点能力」共 15 件（`oss-research-report.md:371/380/390/400/410`） | 过五门验收资产 + 体检报告，多渠道上架 | 0 元（获客资产） | C0 免费 + C1 权益层（consent 兑换，仍 0 元） |
| **收费层** | 别人没做的：行业编排层端到端成果课，下课带走可验收的产线而非知识点 | 5 门端到端课（课程一至五，`oss-research-report.md:367-415`） | 自产 skill 包内嵌交付 + Agent Release 六要素验收单即合同 | 199–1999 元一次性（假设，避开 3980–7980 差评带） | 课程学员（一次性付费） |
| **高级会员层** | 别人没想过的：consent-first 轨迹回流闭环 + 治理托管 + 榜单公信力，8 次中英检索确认无先例（`oss-research-report.md:282`） | 「完整 agent Release + agentsight 轨迹回流的 skill 持续升级订阅」（`oss-research-report.md:50`） | skilldock v0 四件套 + 治理随行包 + 增益榜权益 + 我们的软件系统路线 | 按月订阅 / 按成果计价（Lovable credits 模式，`oss-research-report.md:356`） | C2 订阅层 + C3 定制通道（`治理面输出方案.md:98-105`） |

**为什么这么切（供给侧证据，均出自已读材料）**：
1. 免费层的空间：中文 AI 课三级漏斗中间层是差评集中区，「教工具」类训练营（n8n/Dify/Coze 数千元级）最脆弱——工具本身开源且带官方模板库（`oss-research-report.md:354`第 6 条）；知识本身已被 hello-agents 81.1k★ / llm-course 83.2k★ / DeepLearning.AI 107 门免费短课全覆盖。**把别人收费教的「单点工具使用」直接做成配置好、带体检报告的资产送出去**，成本近零（S3 生成式加工边际成本最低，`MASTER-PLAN.md:89`），杀伤力最大。
2. 收费层的空间：真正的空白不在单点能力，而在**行业编排层**（`oss-research-report.md:30`）；「交付成果」型商业模式海外已验证（Lovable 按成果 credits）、中文近乎空白（`oss-research-report.md:355`）。付费点只能落在「交付/验收/担保」（`oss-research-report.md:352`）。
3. 高级会员层的空间：阿里云 AI Agent Handbook 只给范式「不卖课、不卖云」，付费层可卖「把 30 章范式变成可运行交付物」（`oss-research-report.md:298`）；「consent-first + 权益交换 + 轨迹自动沉淀为 skill 升级数据集」的完整闭环无人做（`oss-research-report.md:282`）。

## 1. 免费层：别人收费教的我们免费送

### 1.1 目标人群

- **主人群**：6 类调研人群全覆盖（开店的人 / 公司打工人 / 做图片的人 / 做视频的人 / 做自媒体的人 / 超级个体，`oss-research-report.md:3`）——免费层是课程漏斗顶部，每件免费单点都对准一门收费课的目标人群；
- **次人群**：agent 技能消费者——skills.sh（实测 All Time 安装 1,480,008）、WorkBuddy / Qoder / TRAE 等货架上的 skill 用户（`CATALOG.md:290`、MASTER-PLAN §4.2）。这类人不买课，但贡献调用证据与影响力。

### 1.2 交付物清单（15 件免费单点 + 3 类追加件）

**A. 5 门课的免费单点能力（研究报告原清单，免费层与资产上架共用同一产物，一次生产两处复用——`MASTER-PLAN.md:271`）：**

**B. 工厂自产过验收资产直送**：meeting-minutes（Δ=4.33/胜率 1.0 全胜，`MASTER-PLAN.md:19`）在形式门欠账清零后即免费上架——它是「聚焦单能 skill + 确定性 oracle」的旗舰样张，随附体检报告分发。

**C. 榜单过线外部资产的封装件**：lark-cli（唯一过盲评线，见 §5）——「飞书办公技能包部署模板」免费送，附我们的体检报告与配置文档。

**D. 后备池（暂不排产，条件触发后进）**：做图片人群的修复三件套封装（GFPGAN/Real-ESRGAN/DeOldify——研究报告明示「修复类三件套+IOPaint 全部免费送成单点 skill/MCP 工具」，`oss-research-report.md:144`，但两条已归档需 fork）；自媒体人群的 guizang-social-card-skill 主题定制（AGPL-3.0 注意传染性；该人群因公众号采集断裂暂不开课，`oss-research-report.md:48`）。

**免费层的差异化不是资产本身，而是随行凭证**：每个 skill 附体检报告（五门逐项结论、双臂均分、golden 版本、来源与许可）——豆包 106 包仅 5 个带 evals、license 仅 9/106，ClawHub 约 15% 恶意感染率事件后「可审计的干净 skill」是采购情绪（`MASTER-PLAN.md:191-193`）。**别人免费送裸 prompt，我们免费送带质检凭证的资产**。

### 1.3 定价假设与进入条件

- **定价**：0 元。定位为获客资产而非收入来源（`MASTER-PLAN.md:221`）。
- **对用户的进入条件**：无门槛。
- **对资产的进入条件（红线）**：过五门验收 + 体检报告在位才可分发——paper-to-skill 全败（Δ=−0.5）证明我方产线也会产出负增益资产，「任何资产在过盲评门前不对外分发」（`MASTER-PLAN.md:263`）。
- **C1 权益层（免费层内部的升级通道）**：开观测开关（consent）→ 全资产库解锁 + 月度新资产包 + 新版免费升级推送，仍 0 元（`治理面输出方案.md:99-100`）。

## 2. 收费层：别人没做的端到端成果课

### 2.1 目标人群（按课程分群，全部来自研究报告人群调研）

| 课程 | 目标人群 | 人群核心痛点（研究报告口径） |
|---|---|---|
| 课程二：会议纪要一条龙 | 公司打工人（非技术岗） | 录音变纪要、格式合规、待办追踪；数据不出本机是敏感刚需 |
| 课程一：日更短视频量产 | 做视频的人 | 选题枯竭、日更压力、多平台分发重复劳动 |
| 课程三：门店短视频工厂 | 开店的人（零技术店主） | 缺人缺时间、「开播难、成本高」（媒体验证） |
| 课程四：月度汇报生成器 | 公司打工人 | Excel 台账→公司模板 PPT，「像我公司出的」而非生成质量 |
| 课程五：技能封装工坊 | 超级个体/开发者（唯一需技术背景：命令行+基础 Python） | 想法变工具、能力封装上架、个人 agent 经营 |

### 2.2 交付物（每门课 = 一条可复跑产线 + 四件随行件）

**统一交付结构**（研究报告判断基准逐条落实，`oss-research-report.md:363`）：
1. **端到端产线**（各课验收口径见研究报告 §4，例：课程二=拖入真实录音数分钟出分发言人三段式 Word 纪要+至少一条已登记催办任务，`oss-research-report.md:379`；课程一=当天 ≥10 条成片进 ≥2 平台草稿箱，`oss-research-report.md:369`）；
2. **自产 skill 包**（带体检报告）：课程核心环节全部用自家过验收资产，学员带走的是「产线 + skill 包 + 治理随行包 + 验收单」四件（`MASTER-PLAN.md:272`）；
3. **Agent Release 六要素验收单即合同**（模型及路由/编排/Prompt 与 Skill 版本/工具与权限/Runtime/评估基线，`oss-research-report.md:453`）；
4. **consent-first 观测开关**（默认不采集，开开关换 skill 免费升级——高级层的入口在收费层就已埋下）。

**课程 × 资产状态对照**（沿用 `MASTER-PLAN.md:275-283` 勘误后状态，本轮未重跑评测）：

| 课程 | 依赖工厂资产 | 资产状态 | 收费层动作与排期 |
|---|---|---|---|
| 课程二 | meeting-minutes | **已过验收且全胜**（Δ=4.33/胜率 1.0）+形式门欠账复检 | **首发试点**（D60 试点 1 期）；补说话人映射交互、单位热词表两件自研空白 |
| 课程一 | 短视频三件套 | 待产（D0–30 排产） | 计时试跑→D90 开放报名 |
| 课程三 | 复用课程一 5 组件+店铺资产 Schema | 待产 | 跟随课程一，行业模板边际开发 |
| 课程四 | monthly-report-ppt | **未过确定性评测（任务下发口径），复裁+返工中** | 复裁裁决→返工过线后排期；与研究报告「资产链五门中最薄」判断一致 |
| 课程五 | 工厂 SOP 本身（SPEC+评测协议+上架 SOP+体检报告样例） | **现成**；首批「4 进 1 出：全胜/返工/零增益/负增益」实测记录即教学案例 | D90 教材化改造后开放报名 |

**开发顺序**：先课程二后课程一（工程序押工程风险），推荐优先级押市场潜力——两序分叉不矛盾（`oss-research-report.md:448`、`MASTER-PLAN.md:233`）。

### 2.3 定价假设与进入条件

- **定价**：199–1999 元低价带。依据：调研锚点为 199 元引流带 / 3980–7980 元差评集中带 / 9800–19800 元高端陪跑带，报告建议避开中间带、往「成果交付」或「低价工具化」两端走（`oss-research-report.md:50/349`）。**此为基于价格锚点的推演、非调研事实，D60 用试点实际转化数据校准**（`MASTER-PLAN.md:380`）。
- **开课进入条件（对内，`MASTER-PLAN.md:235`）**：① ≥2 门课的端到端产线可复跑且现场验收彩排通过（课程一「现场 10 条」为待试跑目标值，开课前必须计时试跑）；② 对应 skill 资产过五门（meeting-minutes ✓，短视频三件套待产）；③ 免费层引流达基线（F5：私域列表 ≥300）；④ 收款通路就绪（国内小额收款无开源方案，短期人工发货+私域/知识星球过渡，`oss-research-report.md:454`）。
- **对学员的进入条件**：课程五要求命令行+基础 Python，其余零技术门槛（各课「你需要准备什么」节）。

## 3. 高级会员层：别人没想过的

### 3.1 目标人群

- **C2 订阅层（个人）**：付费课结业学员中的持续经营者——已经带走产线、需要 skill 持续升级与季度体检的人（`治理面输出方案.md:101`）；
- **C3 定制通道（小团队/企业入口）**：有私有化与审计需求的 ToB 线索，通向企业版治理套件（`治理面输出方案.md:102`）；
- **来源**：研究报告判断基准第 2/3 条——高级产品=完整 agent+工具与基础设施按手册范式组件化交付；用户主动选择被观测（consent-first）换 skill 持续升级权益（`oss-research-report.md:7-8`）。

### 3.2 交付物：「整套体系」五件套（kit 范式的落地形态）

**kit 范式的外部实证（均实测在目录中，`CATALOG.md`）**：
- microsoft/azure-skills 官方插件「一次安装三层」：20+ curated skills + Azure MCP Server + 决策树 guardrails（`CATALOG.md:74`）；
- Shopify AI Toolkit：plugin/skills/hooks/.mcp.json 多形态一体分发（`CATALOG.md:75`）；
- anthropics/knowledge-work-plugins：plugin.json+.mcp.json+commands+skills 四件套，11 职能插件（`CATALOG.md:328`）；
- n8n self-hosted-ai-starter-kit：一条 Docker Compose 拉起本地 AI 栈（`CATALOG.md:189`）；
- Docker MCP Catalog：容器化 + 审批制自定义目录（`CATALOG.md:178`）。

**我们的高级会员 kit = 五件套**（「别人没想过」的点不在每件单体，而在**五件打包成一个可升级的体系**且以 consent 闭环串联）：

| # | 件 | 内容 | 来源 |
