# orders.xlsx「订单」表大表分页读取方案（每页 4000 行）

> **给定事实（照录自任务）**：工作簿 `orders.xlsx`，Sheet「订单」，第 1 行为表头，**自第 2 行起共 9,876 行数据**（即数据占第 2…9877 行），列为 A 订单号 | B 客户 | C 金额 | D 状态；所用 Excel MCP 工具（excel-mcp-server 的 `read_range`，见 ASSET-DOC.md §7.3）单次读取有行数上限，需分页。**每页 4000 行。**

---

## 1. 分页方案：3 页，无重叠、无遗漏

**推导**：数据行区间为 `[2, 9877]`（含两端），数据行数 N = 9877 − 2 + 1 = **9,876**。
页数 = ⌈9876 ÷ 4000⌉ = **3 页**（前 2 个整页覆盖 8,000 行，第 3 页余 1,876 行）。
通项（i = 1,2,3）：起行 = 2 + (i−1)×4000；止行 = min(2 + i×4000 − 1, 9877)。

| 页 | 行范围（含起止行号） | `read_range` 的 range 参数 | 本页行数 | 本页单元格数（4 列） |
|---|---|---|---|---|
| 第 1 页 | 第 **2** ～ **4001** 行 | `A2:D4001` | 4,000 | 16,000 |
| 第 2 页 | 第 **4002** ～ **8001** 行 | `A4002:D8001` | 4,000 | 16,000 |
| 第 3 页 | 第 **8002** ～ **9877** 行 | `A8002:D9877` | **1,876** | 7,504 |
| 合计 | 第 2 ～ 9877 行 | — | **9,876** | 39,504 |

相邻页衔接：第 2 页起行 4002 = 第 1 页止行 4001 + 1；第 3 页起行 8002 = 第 2 页止行 8001 + 1 —— 首尾相接、端点不重复，故**无重叠、无遗漏**。

> **实现注意（依据 ASSET-DOC §7.3 / §8）**：每页 4,000 行 × 4 列 = 16,000 单元格，低于单次调用 100,000 单元格的规模上限，可整页一次读取；但高于 `read_range` 的 `max_cells` 默认值 2000，**调用时须显式传 `max_cells`（建议 ≥ 16,000，如 20,000）**，否则服务器会自行截断分页。若返回 `truncated: true`，按其 `next_range` 续读至 `truncated: false` 为止。

---

## 2. 核对总量的方法

**页行数之和** = 4,000 + 4,000 + 1,876 = **9,876**，应等于给定数据总行数 **9,876**。核对分四层：

1. **逐页计数**：每页行数 = 止行 − 起行 + 1（A1 记法两端均含端点）→ 4,000 / 4,000 / 1,876。
2. **求和对账**：Σ页行数 = 9,876 == 任务给定总数 9,876 ✓；任何不等即说明页边界算错。
3. **跨度对账**：各页区间连续（下一页起行 = 上一页止行 + 1），故总跨度 = 9877 − 2 + 1 = 9,876，与求和一致 ✓。
4. **运行时兜底核验**（本方案设计，未实际执行读取）：用 `describe_sheet`（ASSET-DOC §7.2，只读了解结构）确认已用区域末行确为 9877；读完第 3 页后再探测 `A9878:D9878`，应返回空，证明其后无残留数据。

> 本方案的算术已在本机用 Python 实测验证：`pages=3`，三页分别为 `A2:D4001(4000)`、`A4002:D8001(4000)`、`A8002:D9877(1876)`，`sum=9876==N True`，衔接检查与跨度检查均 `True`。

---

## 3. 两个最易出错的边界及本方案的规避

### ① 首行偏移（数据起点是第 2 行，不是第 1 行）

**错法**：第 1 行是表头，若从 `A1` 起读，表头会被当作一条数据混入第 1 页（第 1 页变成 4,001 行内容），且后续所有页整体错位一行——第 1 页若仍按"止行 4001"收口，`D4001` 一行会被第 2 页的 `A4002` 起重复覆盖，既污染又重叠。
**本方案规避**：显式固定**数据原点 = 第 2 行**，一切页边界由"起行 = 2 + (i−1)×4000、止行 = 起行 + 4000 − 1"推导（A1 记法含两端，故减 1），并强制约束"下一页起行 = 上一页止行 + 1"。表头第 1 行**永不进入任何页区间**，第 1 页 `A2:D4001` 恰好 4,000 条数据。

### ② 末页余量（9,876 不是 4,000 的整数倍）

**错法**：9876 = 2 × 4000 + **1,876**，余数非零。若第 3 页仍按整页发 `A8002:D12001`，会越界读 2,124 个不存在数据的行（读出空值、把账面行数虚增到 12,000，对账失败）；反过来若只发前 2 个整页了事，则漏掉最后 1,876 行。
**本方案规避**：末页止行用**钳制公式** min(2 + 3×4000 − 1, 9877) = **9877**，即第 3 页固定为 `A8002:D9877`、恰 1,876 行，绝不越过真实末行；并以第 2 节的对账（4,000+4,000+1,876 = 9,876）+ 末行后探针 `A9878:D9878` 为空双重确认收口。
