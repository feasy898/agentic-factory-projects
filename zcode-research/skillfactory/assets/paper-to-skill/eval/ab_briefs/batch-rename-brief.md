# 能力简报：批量重命名文件（A/B 任务材料 · ab-001）

## 目标能力

把指定目录下一批匹配给定模式的文件，按统一模板批量重命名。

## 需求要点

- **输入**：目录路径、匹配 pattern（如 `*.log`）、目标命名模板（固定前缀 + 3 位序号 + 保留原扩展名，如 `report_001.log`）。
- **两种模式**：`dry-run` 只打印"原路径 → 新路径"预览清单、不落盘；`apply` 实际执行重命名。
- **冲突处理**：目标文件名已存在时**跳过并记录**，绝不覆盖已有文件。
- **产物**：一份重命名清单（原路径 → 新路径 + 状态：renamed / skipped / would-rename），顺序确定（按原文件名排序）。
- **适用对象**：命令行使用者或 agent（该 SKILL.md 的读者）。

## 边界

- 不递归子目录（除非明确要求）；不改文件内容；不处理重命名过程中的并发冲突。
