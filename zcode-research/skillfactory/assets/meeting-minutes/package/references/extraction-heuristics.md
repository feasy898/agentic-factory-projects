# extraction-heuristics.md — 待办表格「负责人 / 期限」确定性提取

> 何时读：需要手工填待办的负责人/期限两列，或核对脚本提取结果时。依据 spec.md R4/R5。
>
> 红线：**只从该条内容原文按下列规则提取**；全部规则未命中一律填「待定」，禁止语义推断、禁止编造人名或日期。负责人/期限仅作用于待办表格，决议/风险条目不解析这两列。

## 1. 负责人（按序尝试，先命中先用）

| # | 规则 | 提取结果 | 例 |
|---|---|---|---|
| 1 | 句中出现「我负责」或「我们负责」 | 该行**说话人** | 「我负责盯这件事」→ 说话人 |
| 2 | `由 / 让 / 交给 + X + 负责` | X（1–6 字，中英文/数字/·） | 「公告**由医务处负责**」→ 医务处；「**交给王五负责**」→ 王五 |
| 3 | `负责人 是/：/: + X`，X 后跟标点/空白/行尾 | X；X 为 我/我们/自己 时替换为**说话人** | 「**负责人是我**，本周五之前出结果」→ 说话人（如 质检钱主任）；「负责人：钱七」→ 钱七 |
| 4 | `@X`，X 后跟标点/空白/行尾 | X | 「@周九 请跟进」→ 周九 |
| 5 | 都未命中 | **待定** | 「我们需要重新提交检测报告」→ 待定 |

注意：规则 3 的「我→说话人」替换是唯一允许的代词消解；除此之外不改写任何字符。

## 2. 期限（按序尝试，顺序即优先级；提取结果为命中文本本身）

| # | 规则 | 例 |
|---|---|---|
| 1 | 完整日期：`yyyy年m月d日`、`yyyy-m-d`、`yyyy/m/d` 等变体（可带「之前/前」） | 「2026-5-20 到港」→ 2026-5-20 |
| 2 | `m月d日`（可带「之前/前」） | 「**5月20日之前**必须到港」→ 5月20日之前 |
| 3 | `(本周|下周|这周)?周X/星期X`（X=一二三四五六日天；后缀可带「之前/前/以前/底」） | 「**周五前**把名单」→ 周五前；「**本周五之前**出结果」→ **周五之前**；「截止到**周五**」→ 周五 |
| 4 | `本(周|月|季度)(底|末|内)?` | 「本月底前完成」→ 本月底 |
| 5 | `今天 / 明天 / 后天 / 月底前? / 下月 / 本周末` | 「截止到**月底**」→ 月底 |
| 6 | `截止(于|到|至)?X`，X 取 1–8 个非空白且不属于 `，。；;` 的字符 | 前五条都没命中但含「截止…」时 |
| 7 | 都未命中 | **待定** |

关键口径：

- **「本周/下周/这周」前缀只参与命中、不进入提取结果**——提取从 `周X`/`星期X` 起：「本周五之前」→「周五之前」，不是「本周五之前」。
- 顺序即优先级：先查完整日期、再查 m月d日、再查周X……同一行前面规则命中就用前面规则的结果，不再往后看。
  例：「明天发OA，截止到周五各科室把应急预案报上来」——规则 3 命中「周五」，**不**因规则 5 有「明天」而改取明天。
- 后缀「之前/前」属于提取结果的一部分（规则 2/3）。
- 无任何时间语的句子 → 待定，不猜。

## 3. 自查清单（手工填两列时）

- [ ] 每个负责人/期限都能在其条目内容原文中逐字找到（「我→说话人」替换除外）。
- [ ] 没命中就写「待定」——表格里出现原文中不存在的人名或日期即为违规。
- [ ] 「本周/下周/这周」开头的期限已去掉前缀。
