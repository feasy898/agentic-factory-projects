# 清洗口径详解（R1–R6、S1–S5）

> 口径权威来源：`../spec.md` §2/§3/§4。本文补充逐条判定细节与边界样例，供实现与验收对照。
> 所有规则确定性执行：不含时间/随机源，同输入必得同结果。

## R1 空行

- 判定：`日期/事项/类别/数量/状态` 五列**规范化后全部为空串**。
- 处置：不计入「原始行数」，单独计入「空行数」；表头之后的行才参与判定。
- 注意：只要五列之一非空（哪怕只有备注以外的无效字符）就算数据行。仅含表头多余列内容的行也按空行处理（多余列不参与判定）。

## R2 完全重复行去重

- 去重键（五元组）：

  | 分量 | 归一化 |
  |---|---|
  | 日期 | 可解析 → ISO `YYYY-MM-DD`；否则**原文**（strip 后） |
  | 事项 | `str(v).strip()`；None → 空串 |
  | 类别 | 同上 |
  | 数量 | 可解析 → 数值归一化文本：整数去小数点（6.0→`"6"`）；小数至多 2 位去尾零（2.50→`"2.5"`）；否则原文 |
  | 状态 | `str(v).strip()` |

- 键相同只保留**首次出现**，其后每条各计 1 次「重复行数」。
- 恒等式：`去重后行数 = 原始行数 − 重复行数`（验收必查）。
- 边界样例【实测 case2】：字符串日期行 `2026/07/18` 与日期单元格行 `2026-07-18`，其余四列相同 → **算重复**（日期先归一化再比较），保留先出现的那条。
- 数量 `6`（int）与 `"6"`（字符串）归一化后同为 `"6"` → 其余列相同即判重复。

## R3 缺失日期

- 缺失来源：单元格为空、文本为五种支持格式之外的（如「待定」）。
- 处置：**不进入**月度趋势图与 `月度数量合计`；计入「缺失日期行数」；其余统计（合计、类别、状态、完成率）照常包含该行。
- 推论：有缺失日期行时 `月度数量合计 之和 ≤ 数量合计`（验收必查）。

## R4 缺失类别 / 缺失状态

- 类别空 → 归入「未分类」；状态空 → 归入「未知」。
- 两桶照常出现在类别明细表格、类别条目数、状态占比图、状态条目数中。

## R5 缺失数量

- 缺失来源：空、bool、非法字符串（`"待定"` 等）。
- 处置：按 **0** 参与求和；计入「缺失数量行数」；条目数统计不受影响。
- 边界样例【实测 case2】：数量为字符串 `"6"` 的行**正常计入**合计，缺失数量行数不增加。

## R6 完成态与阻塞

- 完成态：状态**全等**「已完成」或「完成」（非子串、不 trim 大小写变体——trim 在规范化时已做）。
- 阻塞：状态文本**包含**「阻塞」子串即计（如「已阻塞」「部分阻塞」）。
- 一行状态可同时计入完成态统计与阻塞统计的判定互不排斥（完成态全等匹配不含「阻塞」字样，实际互斥）。

## S1–S5 汇总口径

- **S1 数量合计**：对去重后行求和；缺失按 0、负数照加【实测 case3：−3+5+4+6+1+7+2=22】。
- **S2 月度聚合**：按 `YYYY-MM` 聚数量合计与条目数；月份**升序**；缺失日期行不参与。
- **S3 类别/状态排序**：条目数降序、同数按名称 Unicode 升序，即 key `(-条数, 名称)`；「条目最多类别」取排序后第一【实测 case1：线上运维 7 与需求开发 7 并列，取「线上运维」】。
- **S4 完成率**：`已完成条数 ÷ 去重后行数 × 100`，保留 1 位小数（Python round，banker's rounding：`round(0.25,1)=0.2`）；分母为 0 → 0.0。
- **S5 统计区间**：`[最早月, 最晚月]`；无有效月份 → `[]`，同时「条目最多类别」→ `"-"`。

## 文本与数值解析基础（spec §2 I4–I6）

- 文本规范化：`str(v).strip()`；None → 空串；date/datetime → `%Y-%m-%d`。
- 日期格式依次尝试：`%Y-%m-%d`、`%Y/%m/%d`、`%Y.%m.%d`、`%Y年%m月%d日`、`%Y%m%d`（strptime 允许非补零）。
- 数量：int/float 直用；**bool 不算数字**；字符串去半角逗号后 float（`"1,234"`→1234.0）。
- 实现注意：`float()` 能解析的 `"inf"/"nan"` 属非法业务数量，按缺失处理，避免合计被污染。
