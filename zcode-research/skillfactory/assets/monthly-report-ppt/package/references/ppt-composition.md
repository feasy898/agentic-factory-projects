# PPT 组装规则（四页语义与文案生成）

> 对应 spec.md §6（P1–P6）。文件名冻结：`汇报.pptx`；版式 16:9（13.333×7.5in），空白版式自绘，正文字体 Microsoft YaHei（latin + East-Asia 都要设置）。

## 页面结构（前四页语义固定，页数 ≥4）

### P1 封面
- 大标题「月度工作汇报」（44pt 加粗居中）。
- 三行副标题（18pt 居中）：
  - `数据来源：<输入文件名>`
  - `统计区间：YYYY-MM ~ YYYY-MM（N 个月）`；无有效月份 → `无有效月份数据`
  - `有效记录 N 条 ｜ 数量合计 X ｜ 完成率 R%`

### P2 数据概览
- 标题「数据概览」；左侧 ≥6 条要点（15pt）：
  1. `原始行数 A 条：剔除重复 B 条、空行 C 条，去重后有效 D 条`
  2. `覆盖月份：…（N 个月）`
  3. `数量合计：X`
  4. `条目最多类别：…`
  5. `完成率：R%（已完成 C / D）`
  6. `缺失说明：缺失日期 M 行（不计入月度趋势）、缺失数量 K 行（按 0 计入合计）`
- 右侧**内嵌** `月度趋势.png`（约 5.4in 宽）。

### P3 类别明细
- 左侧表格 4 列：`类别 / 条目数 / 数量合计 / 占比`；类别按 S3 排序；**末行合计**（条目数=去重后行数、数量合计=总计、占比=100%）；占比分母=去重后行数。
- 右侧**内嵌** `类别分布.png`（约 5.1in 宽）。

### P4 结论与下月计划（左右两栏）
- 左栏「结论」固定 5 条：
  1. 记录规模：`原始 A 条，剔除重复 B 条、空行 C 条，有效 D 条，数量合计 X`
  2. 覆盖：`覆盖 N 个月（区间），条目最多类别为「…」`
  3. 趋势：≥2 个月 → `末月 M2（Y2）较首月 M1（Y1）上升/下降 P%`（P=|末−首|/首×100 保留 1 位）；首月为 0 → `绝对增量 +Y2`；持平 → `末月 M2 与首月 M1 数量合计持平（均为 Y）`；<2 个月 → 明示 `趋势：<原因>，无法计算趋势`（原因=「仅覆盖 1 个月」或「无有效月份数据」）
  4. 完成情况：`已完成 C 条（R%），未完成 U 条，其中阻塞 B 条`
  5. 数据质量：`缺失日期 M 行、缺失数量 K 行（按 0 计入合计），已如实呈现`
- 右栏「下月计划（末月的次月）」，按条件生成：
  - 有类别 → `保持「条目最多类别」类别的投入强度`
  - 有阻塞 → `优先清理 B 条阻塞事项`
  - 有未完成 → `U 条未完成事项逐项跟进`
  - 有缺失 → `补录缺失数据：缺失日期 M 行、缺失数量 K 行`
  - **末条固定**：`沿用本报表口径按月复盘`
  - 下月 = 数据最末月的次月；12 月 → 次年 1 月；无有效月份则标题不带月份。

### 每页页脚（P6）
- 灰色（#808080）9pt 小字：`数据来源：<文件名> ｜ 口径：剔除空行与完全重复行；缺失数量按 0 计，缺失日期不计入月度趋势；完成=状态恰为「已完成/完成」 ｜ 第 N 页 / 共 4 页`。

## 文案红线（P3）

- **全部文案由数据推导**：不含当前时间、运行环境、随机内容。
- 数字与 summary.json 同源（同一份聚合结果），禁止两处各算一套。
- 月份只来自数据；"下月"来自数据最末月，不与日历今天绑定。
