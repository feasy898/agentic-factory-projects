# 月度汇报生成器（monthly-report-ppt）

## 1. 名称与描述

**monthly-report-ppt**：给一份月度工作台账 Excel（xlsx），确定性地产出 **3 张统计图表 PNG（月度趋势、类别分布、状态占比，中文渲染）+ 1 份 4 页 16:9 汇报 PPT（封面/数据概览/类别明细/结论与下月计划）+ 1 份机器可读的 summary.json**；同输入重跑，产物字节级一致。

## 2. 何时使用 / 何时不用

**何时使用**

- 月度/周期性工作复盘：手头有一份按行记录的台账（日期、事项、类别、数量、状态）；
- 定期向他人汇报：需要"图表 + PPT + 关键数字"三件套，且数字必须可追溯、可复现；
- 需要把脏台账（重复行、空行、缺失值、字符串日期、负数数量）按**固定口径**清洗后出数。

**何时不用**（对应非目标）

- 多工作表合并、多文件批量、目录扫描——本技能只读**第一个工作表**；
- 需要 docx/pdf/HTML 产物，或模板/主题/品牌定制——只出 PNG + pptx，版式语义固定；
- 需要补数据、修数据（补日期、猜数量、改状态）——缺失值按口径如实统计，不做修复；
- "月度"与当前日历月绑定——月份完全来自数据中的日期，与运行时间无关。

## 3. 输入要求

- **格式**：xlsx，只读第一个工作表；以 `data_only=True` 打开（公式取缓存值，无缓存视为空）。
- **表头**：从首行向下找第一个非空行作为表头；表头必须含五列：`日期、事项、类别、数量、状态`；多余列忽略；缺任一列报错退出（exit 2）。
- **日期**：date/datetime 单元格直取；字符串支持 `2026-07-05`、`2026/7/5`、`2026.07.05`、`2026年7月5日`、`20260705` 五种格式（非补零可解析）；其余（如"待定"）视为缺失日期。
- **数量**：数字直取（bool 不算数字）；字符串去半角逗号后按 float 解析（`"6"`→6）；空/非法视为缺失数量（按 0 参与合计）。
- **容忍的脏数据**（自动清洗，引用 spec.md §3 规则编号，详见 §6 与 references/cleaning-rules.md）：
  | 脏数据 | 处置 | 规则 |
  |---|---|---|
  | 全空行 | 不计入原始行数，单独计"空行数" | R1 |
  | 完全重复行 | 只保留首条，其后各计 1 次"重复行数" | R2 |
  | 缺失/不可解析日期 | 不进月度趋势与月度汇总，计"缺失日期行数"，其余统计照常 | R3 |
  | 缺失类别 / 缺失状态 | 归入「未分类」/「未知」，照常出现在图表与表格 | R4 |
  | 缺失/非法数量 | 按 0 参与求和，计"缺失数量行数"，条目数不受影响 | R5 |
  | 完成态/阻塞 | 状态**全等**「已完成/完成」计完成；状态**包含**「阻塞」子串计阻塞 | R6 |
  | 负数数量 | 正常按数值参与求和，不警告不拦截 | N8 |

## 4. 用法

```bash
python package/scripts/monthly_report.py --input <台账.xlsx> --outdir <输出目录>
# scripts/gen_report.py 为同一实现的别名入口，参数完全相同
```

| 参数 | 必填 | 语义 |
|---|---|---|
| `--input` | 是 | 台账 xlsx 路径（第一个工作表，表头含 日期/事项/类别/数量/状态） |
| `--outdir` | 是 | 输出目录；不存在则递归创建，已存在则复用（不清空旧文件） |

**退出码**

| 码 | 条件 | 行为 |
|---|---|---|
| 0 | 成功 | stdout 打印人读摘要（行数/关键汇总/产物路径） |
| 2 | 输入文件不存在；第一个工作表无表头行；表头缺任一必需列 | stderr 中文报错，不产生产物、不写半成品 |

示例：

```bash
python package/scripts/monthly_report.py --input 台账.xlsx --outdir out/2026-09   # → exit 0
python package/scripts/monthly_report.py --input 不存在.xlsx --outdir out/x       # → stderr「输入文件不存在: …」，exit 2
```

## 5. 产物说明

`<outdir>` 内固定 5 个文件（contract §3 冻结文件名，全部在根目录，不建子目录）：

| 文件 | 内容 |
|---|---|
| `月度趋势.png` | 各月数量合计折线图（带数值标注）；8×4.5in @150dpi |
| `类别分布.png` | 各类别条目数条形图（按条数降序、同数按名称升序排列，带数值标注） |
| `状态占比.png` | 各状态条目占比饼图（显示百分比）；6.4×4.8in @150dpi |
| `汇报.pptx` | 16:9（13.333×7.5in）4 页：封面 / 数据概览（内嵌月度趋势图）/ 类别明细（4 列表格含合计行 + 内嵌类别分布图）/ 结论与下月计划（左右两栏）；每页灰色小字页脚 |
| `summary.json` | 机器可读关键数字，UTF-8 |

**summary.json 字段表**（顶层 9 键，缺一不可、不得增删）：

| 顶层键 | 说明 |
|---|---|
| `输入文件` | 源 xlsx 文件名（不含路径） |
| `原始行数` / `重复行数` / `去重后行数` / `空行数` | 清洗四项；恒等式：原始 − 重复 = 去重后 |
| `图数` | 恒为 3 |
| `页数` | pptx 实际页数（4） |
| `图表` | 3 个 PNG 文件名列表 |
| `关键汇总数字` | 见下 |

`关键汇总数字`（14 键）：`数量合计`（去重后求和，缺失按 0、负数照加）；`月份数`、`统计区间`（`[最早月, 最晚月]`，无有效月份为 `[]`）；`月度数量合计`（`{"YYYY-MM": 合计}`，月份升序，缺失日期行不参与）；`类别数`、`类别条目数`、`状态数`、`状态条目数`（计数 dict，含「未分类」「未知」）；`已完成条数`、`完成率`（÷去重后行数×100 保留 1 位小数，无数据为 0.0）；`阻塞条数`；`缺失日期行数`、`缺失数量行数`；`条目最多类别`（排序后第一，无数据为 `"-"`）。

## 6. 清洗口径（可追溯）

全部口径逐条对应 spec.md，判定细节与边界样例见 `references/cleaning-rules.md`：

- **R1 空行**：五列全空 → 不计原始行数，单独计空行数。
- **R2 完全重复去重**：键=（日期可解析→`YYYY-MM-DD` 否则原文；事项；类别；数量可解析→归一化数值文本否则原文；状态），保留首条；恒等式 `去重后行数 = 原始行数 − 重复行数`。
- **R3 缺失日期**：不进月度趋势/月度汇总，其余统计照常包含。
- **R4 缺失类别/状态**：→「未分类」/「未知」。
- **R5 缺失数量**：按 0 求和，计缺失数量行数。
- **R6 完成与阻塞**：「已完成/完成」全等计完成；「阻塞」子串计阻塞。
- **S1–S5 汇总口径**：合计含 0 与负数；月份升序；类别/状态按（条数降序、名称 Unicode 升序）；完成率 1 位小数（banker's rounding）；统计区间取升序首尾。

## 7. 方法论：台账 → 清洗 → 统计 → 选图 → 组 PPT

本技能的完整处理链与取舍规则如下（agent 修改/扩展本技能时按此推理，不要只改表面代码）：

**① 读台账**：只开第一个工作表、`data_only+read_only`；表头前全空行跳过不计数；表头行本身不进任何行数统计。

**② 清洗（顺序固定，全部确定性）**：先 R1 剔空行并计数 → 再 R2 去重并计数（去重键里日期与数量**先归一化再比较**，所以字符串日期 `2026/07/18` 与日期单元格 `2026-07-18` 的同名同行算重复）→ 每行打上"缺失日期/缺失数量"标记（R3/R5），缺失类别/状态就地归桶（R4）。取舍原则：**任何缺失都不阻断、不修复、不猜测**，只换统计口径并如实计数。

**③ 统计**：一律基于去重后行集；合计含按 0 计的行与负数；月度聚合排除缺失日期行；排序键统一用 `(−条数, 名称)`，保证并列时取名靠前者，PPT/图表/summary 三处口径一致。

**④ 选图（图表选型规则）**：

| 数据形态 | 图型 | 理由 |
|---|---|---|
| 有序时间维度上的量（月度数量合计） | 折线 + 数据点数值标注 | 折线表达"趋势/连续性"，标注让汇报时不必读坐标 |
| 类别维度上的计数（各类别条目数） | 条形图（按条数降序、同数按名升序排列，>6 类自动旋转标签） | 条形比饼图更利于类别间精确比较，排序即结论 |
| 部分与整体（各状态占比） | 饼图 + 百分比标注 | 状态数少且构成"整体的一部分"，饼图直观 |
| 维度无数据 | 不画空坐标系，画居中灰色提示文案（如「无有效日期数据」） | 空图比报错更适合批量场景；提示文案也必须确定性 |

   渲染约束：中文一律 Microsoft YaHei 且 `axes.unicode_minus=False`（否则负号变方块，见 case3 的 −3）；尺寸/分辨率固定（折线/条形 8×4.5in、饼图 6.4×4.8in、150dpi）；PNG 写固定 metadata。

**⑤ 组 PPT（取舍规则）**：16:9 空白版式自绘，四页语义固定——封面只放"来源/区间/三个总数"；概览页文字要点在左（≥6 条，含缺失说明）、图在右；明细页表格在左（类别/条目数/数量合计/占比 + 末行合计，占比分母=去重后行数）、图在右；结论页左右两栏（结论 5 条：规模→覆盖→趋势→完成→数据质量；下月计划：保持最大类别投入→清理阻塞→跟进未完成→补录缺失→固定末条"沿用本报表口径按月复盘"）。**全部文案由数据推导**：禁止当前时间、随机内容、模板套话里带日期；趋势比较只用"末月 vs 首月"，首月为 0 改说绝对增量，不足 2 个月明示"无法计算"。

**⑥ 确定性收尾（D1/D2）**：脚本内禁止当前时间/随机源进入产物；pptx 保存后必须把 zip 全部条目时间戳归一化（如 1980-01-01）、core properties 写死常量；写最终文件遇 PermissionError 允许有限次重试。验收方式：同输入连跑两次，5 个产物 md5 逐一比对。

## 8. 错误处理

| 场景 | 表现 |
|---|---|
| 输入文件不存在 | stderr `输入文件不存在: <路径>`，exit 2，无产物 |
| 第一个工作表全空（无表头行） | stderr `工作表为空：没有表头行`，exit 2 |
| 表头缺必需列 | stderr `表头缺少必需列：数量（实际表头：[…]）`，exit 2 |
| 成功 | exit 0，stdout 打印行数/汇总/产物路径摘要 |

不允许其他退出码语义；不应出现未捕获异常崩溃。

## 9. 环境依赖

- Python 3.12+；依赖见 `requirements.txt`：openpyxl>=3.1、matplotlib>=3.11、python-pptx>=1.0。
- 面向 Windows + Microsoft YaHei 字体假设（其他系统中文渲染不保证）。
- matplotlib 必须 Agg 后端（无显示环境可运行）。
